# Getting Started

Welcome to the Construction ERP. This guide explains how everyday features work, based on the screens in the app.

## Sign in
1. Open **/login** and enter your full name and password.
2. If your email is not verified yet, use **Resend activation** from the login error message.
3. New accounts open **/activate?token=…** to set a password, then return to login.
4. Forgotten passwords use **/forgot-password** and **/reset-password?token=…**.

## First login
If HR requires a password change, the app sends you to **/change-password** before the dashboard. After that you land on **/** (home).

## Find your way
- **Sidebar** — modules you are allowed to open (staff without HR access see a shorter list: Dashboard, New Request, Approvals, Evaluation Inbox, Announcements, and My Profile).
- **New Request** — **/approvals/new** opens a picker of forms you can submit.
- **User Guide** — the help icon in the sidebar footer opens this portal in a new tab.

## Language
Use the language control in the ERP header for the main UI. This User Guide has its own **EN / 中文** toggle in the top bar.
