# Dashboard

Home is **/** (the path **/dashboard** redirects here). Tabs are controlled by `?tab=`.

## Tabs
| Tab | Query | Who sees it |
| --- | --- | --- |
| Overview | `?tab=overview` | HR / executives (`hr.view` or HR Manager, System Administrator, …) |
| Payroll & OT | `?tab=payroll-ot` | Same HR set |
| Operations | `?tab=operations` | Same HR set |
| My Team | `?tab=my-team` | Supervisors / team leads (or when team data exists) |
| My Work | `?tab=my-work` | Everyone |

## Quick actions
Header shortcuts (capability-gated) can open new leave, OT, per diem, or flight forms, plus **/approvals** and **/profile**.

## Tips
- Widgets show leave balance, OT, site time, and pending requests for your scope.
- Invalid `tab` values reset after profile/stats load.
