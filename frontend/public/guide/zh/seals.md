# 公章与项目章

当文件需要加盖公司公章或项目章时，请提交用章申请。您填写文件信息和需用日期，然后提交审批。批准后，人事为文件盖章并登记已用印的文件。

**找到与您相关的部分**

| 您的身份 | 请阅读 |
| --- | --- |
| 员工 | 申请用章、跟踪申请，以及申请被退回时怎么办 |
| 用章审批人 | 如何审批用章申请 |
| 人事及行政人员 | 查看所有申请、用印，以及导出或导入申请 |

## 如何申请用章

*（员工）*

1. 在左侧菜单中，进入**新建申请**。
2. 点击**公章使用**或**项目章使用**。表单分三步：**申请详情**、**待用印文件**和**确认并提交**。


## 第 1 步 — 申请详情

*（员工）*

1. **文件名称**（必填）：需要盖章的文件名称。
2. **描述**：需要用章的原因。
3. **需用日期**（必填）：今天或之后的日期。
4. **紧急程度**（必填）：**一般**、**中等**、**紧急**或**特急**。
5. **类别**（必填）：**合同**、**函件**、**证书**、**报告**、**图纸**或**其他（请填写）**。选择**其他（请填写）**时，请填写**其他类别**。
6. **份数**：需要盖章的份数。
7. 点击**下一步**。

## 第 2 步 — 待用印文件

*（员工）*

1. 点击**选择文件（可选）**，上传需要盖章的文件。
2. 点击**下一步**。

## 第 3 步 — 确认并提交

*（员工）*

1. 核对详情和附件。
2. 如需修改，点击**上一步**。
3. 点击**提交申请**。

> **提交后：** 您的申请已发送审批。申请被批准或退回时，您会收到通知。

---

## 如何跟踪您的用章申请

*（员工）*

1. 在左侧菜单中，进入**审批** → **我的申请**，打开该申请。
2. 盖章完成后，状态会显示**已用印**，并附有**已用印文件（凭证）**。

---

## 申请被退回时怎么办

*（员工）*

申请被退回时，您会收到退回通知。打开申请即可查看原因。

1. 在左侧菜单中，进入**审批** → **我的申请**，打开状态为**已退回**的申请。横幅会显示**此申请已退回**以及审批人的备注。
2. 阅读备注。
3. 点击申请顶部的**重新提交**，在**重新提交申请**中填写**给审批人的备注（可选）**，如需更正文件，点击**添加附件**上传。
4. 点击**重新提交**。申请会从审批链的第一步重新开始。

## 如何审批用章申请

*（用章审批人）*

申请转到您这里时，您会收到需要审批的通知。

1. 在左侧菜单中，进入**审批** → **待我处理**，打开该申请。
2. 核对文件名称、类别、份数、需用日期和附件。
3. 选择**批准**、**退回**（填写**给提交人的备注**）或**拒绝**（填写**拒绝原因**）。提交人会收到通知。

## 如何查看所有用章申请

*（人事及行政人员）*

1. 在左侧菜单中，进入**运营** → **公章使用**或**项目章使用**。
2. 顶部统计显示**全部**、**草稿**、**待处理**、**已批准**和**已拒绝**。
3. 可按申请编号、文件名称或员工搜索。
4. 列表显示**申请编号**、员工、**文件名称**、紧急程度、**需用日期**、状态和当前层级。
5. 点击某条申请即可打开。

## 如何用印

*（人事 — 仅限已批准的申请）*

1. 打开已批准的申请。
2. 核对**待用印文件**。
3. 为文件盖章。
4. 在**用印**部分，点击**选择文件（可选）**上传已盖章的文件，然后点击**用印**。

> **用印后：** 状态变为**已用印**。申请会显示**用印人**和**完成时间**，已盖章的文件会出现在**已用印文件（凭证）**中。

---

## 如何导出或导入用章申请

*（人事及行政人员）*

- **导出：** 在列表中点击**导出申请**。
- **导入：** 点击**从 Excel 导入**，再点击**下载模板**。导入的申请会创建为**草稿**。附件不会被导入，提交前必须补充文件。

## 人事须知

*（人事及行政人员）*

- **取消。** 只有申请人可以取消申请，且仅限**草稿**或**已提交**状态。
- **直接批准。** 标记为直接批准的申请没有审批人。
