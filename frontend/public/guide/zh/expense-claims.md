# 费用报销

费用报销用于报销您因工作支出的费用，例如交通、餐饮或住宿。您逐条列出每笔费用并附上票据，然后提交审批。批准后，由人事向您付款。

**找到与您相关的部分**

| 您的身份 | 请阅读 |
| --- | --- |
| 员工 | 提交报销、跟踪报销、修改或取消草稿，以及报销被退回时怎么办 |
| 费用报销审批人 | 如何审批费用报销 |
| 人事（人事经理、人事助理、人事专员） | 查看所有报销、标记为已支付、删除、导入和导出 |

## 如何提交费用报销

*（员工）*

1. 在左侧菜单中，进入**新建申请**。
2. 点击**费用报销**。表单分三步：**申请详情**、**物品清单**和**确认并提交**。


## 第 1 步 — 申请详情

*（员工）*

1. **标题**（必填）：审批人容易识别的简短标题，例如 *"3 月 Adama 现场"*。
2. **描述**（选填）：用途或项目。
3. 点击**下一步**。

## 第 2 步 — 物品清单

*（员工）*

1. 点击**添加物品**，打开**添加报销明细**窗口。
2. 填写：
   - **类别**（必填）：例如交通、餐饮或住宿。
   - **描述**（必填）：这笔费用是什么。
   - **费用日期**（必填）：不能是未来日期。
   - **金额**（必填）：以 ETB 计。
   - **票据**（必填）：一个或多个 PDF、JPG 或 PNG 文件。添加的所有文件都属于这一条明细（例如发票和付款凭证）。
3. 点击**保存**。该明细会出现在列表中，显示**日期**、**类别**、**描述**、**金额**和**票据**。
4. 每笔费用重复以上步骤。如需修改或移除某一行，使用该行的**更新**或**删除**。
5. 点击**下一步**。


## 第 3 步 — 确认并提交

*（员工）*

1. 核对明细和**合计**。
2. 如需修改，点击**上一步**。
3. 点击**提交报销**发送审批，或点击**保存为草稿**稍后完成。草稿可以暂不上传收据，但提交前每条明细都必须有收据。

> **提交后：** 页面会提示*"费用报销已提交审批"*。您的报销已发送审批。报销被批准或退回时，您会收到通知。

> **保存草稿后：** 页面会提示*"草稿已保存。稍后可在“我的费用报销”或“我的草稿”中完成并提交。"*，并打开状态为**草稿**的报销。请见*如何完成草稿报销*。

### 表单无法提交的原因

- *"请输入报销标题"*：标题为空。
- *"请至少添加一条带收据的费用明细"*：报销中没有明细。
- *"请上传该明细的收据"*：某条明细缺少票据。
- 费用日期是未来日期。

## 如何跟踪您的费用报销

*（员工）*

1. 在左侧菜单中，进入**审批**，点击**我的申请**标签页。列表显示您已提交的报销，以及每条报销正在等待的审批人。
2. 点击某条报销即可打开，查看每条明细及其收据、**审批链**，以及**已支付**处显示的人事付款日期。已批准但尚未付款的报销显示**未支付**。
3. 已保存但尚未提交的报销在**审批** → **我的草稿**中。

如果有员工向您汇报，左侧菜单中还会有**薪酬与差旅** → **费用报销**，列出您本人和团队的报销，并显示**全部**、**草稿**、**审核中**、**已批准**和**已拒绝**统计。

**状态说明**

| 状态 | 含义 |
| --- | --- |
| 草稿 | 已保存，尚未发出。 |
| 已提交 | 已发送审批。 |
| 审批中 | 正在审批。 |
| 已退回 | 已退回给您修改。 |
| 已批准 | 已批准，等待付款。付款后会显示**已支付**及日期。 |
| 已拒绝 | 未获批准。 |
| 已取消 | 已取消。 |

## 如何完成草稿报销

*（员工 — 仅限报销为**草稿**时）*

点击**保存为草稿**而不是**提交报销**时，报销即为**草稿**。

1. 用以下任一方式打开草稿：
   - **审批** → **我的草稿**，点击该报销（或旁边的**编辑**）。
   - 如果有员工向您汇报：**薪酬与差旅** → **费用报销**，点击状态为**草稿**的报销。
2. 如需修改标题或描述，点击**更新**，修改后点击**保存**。
3. 如需添加明细，点击**添加物品**；如需修改或移除某条明细，点击该明细的 **⋯**，选择**更新**或**删除**。一条明细可以有多个收据文件；在**更新**中上传新文件会替换原有收据。
4. 如果页面提示*"仍有 N 条明细缺少收据，提交前请补齐。"*，请补充缺少的票据。
5. 点击**提交报销**，并在**提交费用报销？**中确认。

---

## 如何取消费用报销

*（员工 — 报销为**草稿**或**已提交**时）*

1. 打开该报销。
2. 点击**取消报销**。
3. 在**取消费用报销？**中确认。报销及其审批申请都会被取消。

---

## 报销被退回时怎么办

*（员工）*

报销被退回时，您会收到退回通知。打开报销即可查看原因。

1. 在左侧菜单中，进入**审批** → **我的申请**，打开状态为**已退回**的报销。横幅会显示**此申请已退回**以及审批人的备注。
2. 阅读备注。
3. 如需修改报销，点击报销顶部的**编辑**（或在**我的申请**列表中该报销旁的**编辑**）。编辑页面顶部会显示审批人的备注。
4. 如有需要，修改**标题**或**描述**。在**明细**中点击**添加物品**新增明细，或使用明细上的编辑和删除按钮。明细的修改会立即保存，每条明细都必须有收据。
5. 点击**保存**。页面会提示*"修改已保存。"*，并回到申请页面，状态仍为**已退回**。
6. 准备好后，点击申请顶部的**重新提交**（如无需修改，可跳过编辑）。在**重新提交申请**中，填写**给审批人的备注（可选）**，如有需要点击**添加附件**，然后点击**重新提交**。

重新提交后，报销会从审批链的第一步重新开始。

## 如何审批费用报销

*（费用报销审批人）*

报销转到您这里时，您会收到需要审批的通知。

1. 在左侧菜单中，进入**审批** → **待我处理**，打开该报销。
2. 核对每条明细的**日期**、**类别**、**描述**和**金额**。点击**预览**查看票据。
3. 选择**批准**、**退回**（填写**给提交人的备注**）或**拒绝**（填写**拒绝原因**）。员工会收到通知。

完整步骤请参阅**审批**主题。

## 如何查看所有费用报销

*（人事）*

1. 在左侧菜单中，进入**薪酬与差旅** → **费用报销**，打开**费用报销**。
2. 可按报销编号、标题或员工搜索，或按**员工**筛选。点击**重置**清除筛选。
3. 列表会多显示**员工**列。
4. 点击某条报销即可打开。

## 如何将报销标记为已支付

*（人事 — 仅限已批准的报销）*

1. 打开已批准的报销。
2. 点击**标记为已支付**，打开**将费用报销标记为已支付？**窗口。
3. **付款参考号**（选填）：付款凭证或银行参考号。
4. 确认。

> **确认后：** 页面会提示*"费用报销已标记为已支付。"*报销会显示**已支付**、**支付日期**和**登记人**，员工也能看到已付款。

## 如何删除费用报销

*（人事）*

1. 打开该报销，点击**删除**。
2. 在**删除费用报销？**中确认。报销将被移除，其审批申请会被取消。此操作无法撤销。

## 如何导入或导出费用报销

*（人事）*

- **导出：** 在**费用报销**中点击**导出 Excel**。会导出符合当前搜索和筛选条件的记录。
- **导入报销：** 点击**从 Excel 导入**，再点击**下载模板**。每一行需要 **employeeEmail** 或 **employeeId** 和 **title**，并为一张**草稿**报销添加一条明细。员工和标题相同的行会归入同一张报销。票据不会被导入，报销也不会自动提交：提交前必须上传票据。
- **向草稿导入明细：** 打开一张**草稿**报销，点击**从 Excel 导入**，可一次添加多条明细。
