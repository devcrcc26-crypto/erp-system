# 费用报销

费用报销用于收回您为工作支出的费用，例如交通、餐饮、住宿等。您逐项列出每笔费用并附上发票，检查后提交审批。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 提交自己的费用报销，并在**审批**和**薪酬与差旅** → **费用报销**中跟踪。 |
| 审批人 | 审批在**审批**中转到您这里的报销单。 |
| 人事（人事经理、人事助理、人事专员） | 在**薪酬与差旅** → **费用报销**中查看所有人的报销单并处理。 |

**入口位置**
- 提交：**新建申请** → **费用报销**。
- 跟踪：侧边栏 → **薪酬与差旅** → **费用报销**。员工只能看到自己的报销；人事可以看到全部。

---

## 如何提交费用报销

1. 进入 **新建申请** → **费用报销**。
2. **申请详情：** 填写一个审批人容易识别的**标题**，并可选填**说明**（用途、项目等）。
3. **费用明细：** 点击**添加明细**，为每笔费用填写：
   - **费用日期**
   - **类别**（例如：交通、餐饮、住宿）
   - **描述**
   - **金额**
   - **发票**：PDF 或图片格式。每笔费用都必须附发票。
   - 点击**保存**将该条加入列表。使用**编辑明细**可修改，或将其删除。
   - 金额会自动折算为埃塞俄比亚比尔（ETB）计入审批总额。
4. **审核并提交：** 检查明细和**合计**，然后点击**提交报销单**。

> **接下来会发生什么：** 报销单进入审批流程，您可以在**审批**中跟踪。如果审批人将其退回，请在**审批**中修改后重新提交。

---

## 哪些情况会导致无法提交

- 没有标题。
- 没有明细。至少需要一条带发票的明细。
- 某条明细缺少类别、描述、日期、金额或发票。

---

## 小贴士

- 添加明细时同时附上发票，不要等以后再补。缺少发票的报销单无法提交。
- 每次出差或每个用途使用一张报销单，便于审批人逐一核对。
