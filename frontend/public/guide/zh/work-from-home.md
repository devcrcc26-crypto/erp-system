# 居家办公

居家办公申请用于申请一天或多天在家办公。您选择日期并填写原因。申请会提交给您的专业负责人审批。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 为自己申请居家办公日，并在**审批**中跟踪。 |
| 专业负责人 | 审批团队成员的居家办公申请。 |
| 人事（人事经理、人事助理、人事专员） | 无需审批，直接安排居家办公日，并在**考勤与假期** → **居家办公**中查看全部日期。 |

**入口位置**
- 申请：**新建申请** → **居家办公**（或打开 `/approvals/new/work-from-home`）。
- 人事日历：侧边栏 → **考勤与假期** → **居家办公**（仅人事可见）。

---

## 如何申请居家办公

1. 进入 **新建申请** → **居家办公**。
2. **代他人提交（可选）：** 选择**本人**，或选择您要为其提交的**员工**（如您有此权限）。
3. **详情：**
   - 选择**日期**。每次申请的天数有上限，表单会显示。周日、公共假期以及已被占用的日期会自动跳过。
   - 填写**原因**。您的专业负责人会看到此原因。
4. 点击**审核**，检查摘要后点击**提交申请**。

> **接下来会发生什么：** 申请提交给您的专业负责人。您可以在**审批**中跟踪。

---

## 哪些情况会导致无法提交

- 没有填写开始或结束日期。
- 所选日期都不能居家办公（例如全部是周日或假日）。
- 日期预览失败。请检查日期后重试。

---

## 人事：直接安排居家办公

人事无需审批，可在**考勤与假期** → **居家办公**中直接安排居家办公日。该页面显示全公司的居家办公日历。
