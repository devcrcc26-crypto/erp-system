# 绩效考核

绩效考核是人事按周期组织的评估。团队负责人和专业负责人在**我的考核收件箱**中完成其团队的考核。员工可以在自己的资料中查看考核结果。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 在**我的资料** → **考核**中查看自己的考核。 |
| 团队负责人、专业负责人 | 在**我的考核收件箱**中完成并提交团队成员的考核。 |
| 人事（人事经理、人事助理、人事专员） | 组织考核周期、设置考核模板，查看全部考核，并在**人员** → **绩效**下使用同一收件箱。 |

**入口位置**
- 您的考核：侧边栏 → **我的资料** → **考核**。
- 考核收件箱：侧边栏 → **我的考核收件箱**（团队负责人和专业负责人），或 **人员** → **绩效** → **我的考核收件箱**（人事）。
- 人事页面（仅人事）：**人员** → **绩效** → **全部考核**、**考核周期**和**考核模板**。

---

## 如何完成考核（团队负责人或专业负责人）

1. 打开**我的考核收件箱**，其中列出等待您处理的考核。
2. 打开某位团队成员的考核。
3. 按模板为每项标准打分，并填写评语。
4. 提交考核。

---

## 如何查看自己的考核（员工）

1. 进入 **我的资料** → **考核**。
2. 打开某项考核，查看已与您共享的分数和评语。

---

## 小贴士

- 请在考核周期截止前完成考核，否则考核会一直停留在收件箱中。
- 考核模板和周期日期由人事设置。如果模板缺少某项标准，请咨询人事。
