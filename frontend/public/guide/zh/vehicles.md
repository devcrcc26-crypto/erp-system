# 车辆

车辆相关申请包括三类：申请使用公司车辆、记录公务车加油、以及报告设备或车辆的检修或维修。每一类都是独立的申请类型。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 如果您的账户有权限，可申请用车、记录加油，或报告检修或维修。在**审批**中跟踪。 |
| 审批人 | 审批在**审批**中转到您这里的申请。 |
| 车队与人事人员 | 在**运营** → **车队与资产**下查看全部车辆申请并处理。 |

**入口位置**
- 提交：**新建申请**，然后选择**用车申请**、**车辆加油**或**检修申请**。
- 列表：侧边栏 → **运营** → **车队与资产** → **用车申请**、**车辆加油**或**检修申请**（仅车队权限可见）。
- 公司车辆台账：侧边栏 → **运营** → **车队与资产** → **公司车辆**（仅人事可见）。

---

## 如何报告检修、保养或维修

1. 进入 **新建申请** → **检修申请**。
2. **设备：** 选择**使用已分配的公司资产**并选定资产；或选择**手动输入设备**，然后填写**设备名称**、**品牌**、**型号**和**年份**。
3. **申请详情：** 填写**地点**、**检修类型**（*检查*、*保养*或*维修*）、**紧急程度**（*紧急*、*加急*、*中等*或*一般*）、问题**描述**，并可选填**建议方案**。
4. 点击**审核并提交**，检查详情后点击**提交申请**。

> **接下来会发生什么：** 申请进入审批流程，您可以在**审批**中跟踪。

---

## 如何申请用车和记录加油

- **用车申请：** 新建申请 → **用车申请**。填写用车行程信息后提交。
- **车辆加油：** 新建申请 → **车辆加油**。填写车辆、日期和燃油信息后提交。

请按照每个表单的步骤操作。**审核并提交**步骤会在提交前显示摘要。
