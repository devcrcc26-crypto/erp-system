# 物料与采购

获取工作所需物品有三种申请：

- **采购申请**：申请公司购买物品。
- **领料申请**：从仓库领取材料。
- **低值易耗品申请**：申请办公或现场用的小额物品，每件低于 5,000 埃比尔。

**找到与您相关的部分**

| 您的身份 | 请阅读 |
| --- | --- |
| 员工 | 提交各类申请、跟踪申请，以及申请被退回时怎么办 |
| 相关申请审批人 | 如何审批物料或采购申请 |
| 采购、仓库及人事人员 | 查看所有申请、更正明细、导出和导入 |

## 如何提交采购申请

*（员工）*

1. 在左侧菜单中，进入**新建申请**。
2. 点击**采购申请**。表单分三步：**申请详情**、**物品清单**和**确认并提交**。


## 第 1 步 — 申请详情（采购）

*（员工）*

1. **标题**（必填）：申请的简短名称。
2. **需求日期**：需要物品的日期。
3. **供应商名称**、**供应商邮箱**和**供应商电话号码**：如果已有供应商可填写。邮箱必须有效。
4. **申请理由**（必填）：说明为什么需要采购。
5. 点击**下一步**。

## 第 2 步 — 物品清单（采购）

*（员工）*

1. 点击**添加物品**，打开**新明细**窗口。
2. 填写：
   - **物品名称**（必填）
   - **描述（型号 / 规格）**，例如*"办公笔记本电脑（HP i7，16GB 内存）"*
   - **数量**（必填）和**单位**（必填），例如 pcs、box 或 kg
   - **单价**（必填），单位为埃比尔
   - **物品图片**（可选）：JPEG、PNG、WebP 或 GIF 照片
3. 点击**保存**。每行**合计**和**预计总费用**会自动计算。
4. 添加所需的全部物品，然后点击**下一步**。


## 第 3 步 — 确认并提交（采购）

*（员工）*

1. 核对详情、物品和**预计总费用**。
2. 在**附件材料**中，点击**选择证明文件**上传报价单或规格书（可选）。
3. 如需修改，点击**上一步**。
4. 点击**提交申请**。

> **提交后：** 页面会提示*"采购申请已提交审批"*。您的申请已发送审批。申请被批准或退回时，您会收到通知。

## 如何提交领料申请

*（员工）*

1. 在左侧菜单中，进入**新建申请**。
2. 点击**领料申请**。表单分三步：**申请详情**、**物品清单**和**确认并提交**。


## 第 1 步 — 申请详情（领料）

*（员工）*

1. **标题**（必填）。
2. **出行目的**（必填）：说明材料的用途。
3. **需求日期**（可选）。
4. **仓库位置**（可选）：从哪个仓库领取。
5. 点击**下一步**。

## 第 2 步 — 物品清单（领料）

*（员工）*

1. 点击**添加物品**，为每一行填写：
   - **物品名称**（必填）
   - **物品编码**：如知道库存或目录编码可填写
   - **数量**（必填）和**单位**（必填）
   - **描述**
2. 点击**保存**。至少添加一条明细。
3. 点击**下一步**。

## 第 3 步 — 确认并提交（领料）

*（员工）*

1. 核对摘要。
2. 如有需要，在**附件材料**中上传图纸或规格书。
3. 点击**提交申请**。

> **提交后：** 页面会提示*"材料领用已提交审批"*。您的申请已发送审批。申请被批准或退回时，您会收到通知。

---

## 如何提交低值易耗品申请

*（员工）*

本表单仅用于低值易耗品。每项估价须低于 5,000 埃比尔，每份申请最多 20 项。更高价值的物品请使用**领料申请**或**采购申请**。

1. 在左侧菜单中，进入**新建申请**。
2. 点击**低值易耗品申请**。表单分三步：**申请详情**、**物品清单**和**确认并提交**。

## 第 1 步 — 申请详情（低值易耗品）

*（员工）*

1. **标题**（必填）和**出行目的**（必填）。
2. **需求日期**（可选）。
3. 点击**下一步**。

## 第 2 步 — 物品清单（低值易耗品）

*（员工）*

1. 点击**添加物品**，为每一行填写**物品名称**（必填）、**物品编码**、**型号 / 规格**、**描述**、**数量**（必填）和**单位**（必填）。
2. 点击**保存**。在某一行上点击**更新**或**删除**可修改或移除该行。
3. 点击**下一步**。

## 第 3 步 — 确认并提交（低值易耗品）

*（员工）*

1. 核对申请和物品。
2. 在**声明**中勾选*"本人确认此申请中的所有物品均为低值易耗品，每件预计价值低于5000埃比尔。"*不勾选将无法提交。
3. 如有需要，在**附件材料**中上传报价单或装箱单。
4. 点击**提交申请**。


> **提交后：** 页面会提示*"低值易耗品申请已提交审批"*。您的申请已发送审批。申请被批准或退回时，您会收到通知。

### 表单无法提交的原因

- *"请至少添加一条明细"*。
- *"每份申请最多 20 项"*：请把物品拆分为两份申请。
- *"请确认低值易耗品声明"*：请勾选声明。

## 如何跟踪您的申请

*（员工）*

1. 在左侧菜单中，进入**审批** → **我的申请**，打开该申请。
2. 您可以看到详情、物品、附件和状态。

---

## 申请被退回时怎么办

*（员工）*

申请被退回时，您会收到退回通知。打开申请即可查看原因。

1. 在左侧菜单中，进入**审批** → **我的申请**，打开状态为**已退回**的申请。横幅会显示**此申请已退回**以及审批人的备注。
2. 阅读备注。
3. 如需修改申请，点击申请顶部的**编辑**（或在**我的申请**列表中该申请旁的**编辑**）。表单会带出您之前填写的内容，审批人的备注显示在顶部。修改后点击**保存**。页面会提示*"修改已保存。"*，并回到申请页面，状态仍为**已退回**。领料申请可修改基本信息，并新增、修改或删除物品明细。
4. 准备好后，点击申请顶部的**重新提交**（如无需修改，可跳过编辑）。在**重新提交申请**中，填写**给审批人的备注（可选）**，如有需要点击**添加附件**，然后点击**重新提交**。

重新提交后，申请会从审批链的第一步重新开始。

> **重新提交后：** 页面会提示*"申请已重新提交"*。

> **注意：** 只有**领料申请**可以**编辑**。采购申请和耗材申请无法自行修改物品明细：请点击**重新提交**并在备注中说明需要更改的内容，或取消申请后重新提交。如需补充新的报价单或文件，请在点击**重新提交**时添加。

## 如何审批物料或采购申请

*（相关申请审批人）*

申请转到您这里时，您会收到需要审批的通知。

1. 在左侧菜单中，进入**审批** → **待我处理**，打开该申请。
2. 核对**申请详情**和**物品清单**中的每一行。采购申请请核对**单价**、**合计**和**预计总费用**，并查看**附件**。
3. 选择**批准**、**退回**（填写**给提交人的备注**）或**拒绝**（填写**拒绝原因**）。提交人会收到通知。

## 如何查看所有申请

*（采购、仓库及人事人员）*

1. 在左侧菜单中，进入**运营** → **采购**，点击**采购申请**、**材料领用**或**低值易耗品**。
2. 顶部统计显示**全部**、**草稿**、**待处理**、**已批准**和**已拒绝**。
3. 可搜索或按**员工**筛选，点击某条申请即可打开。
4. 如需下载，在列表中点击**导出申请**；在打开的申请中点击**导出明细**或**导出 PDF**。

## 如何更正草稿或已退回申请的明细

*（采购、仓库及人事人员）*

1. 在列表中打开该申请。已退回的申请会显示*"该申请已退回修改。"*
2. 在某条明细上点击**更新**进行修改并**保存**，或点击**删除**并在**删除明细？**中确认。采购申请的总额会重新计算。
3. 点击**添加物品**新增一行。领料申请还可以点击**从 Excel 导入**批量添加明细。
4. 之后由员工在**审批**中重新提交。

## 人事须知

*（采购、仓库及人事人员）*

- **审批人。**
  - 采购申请始终由总经理审批。
  - 领料申请依次由员工的直属上级、人事专员和总经理审批。提交人本身角色已覆盖的步骤会跳过。
  - 低值易耗品申请仅由人事专员审批。人事专员及更高级别人员提交自己的低值易耗品申请时会直接批准。
- **取消。** 只有申请人可以取消申请，且仅限**草稿**或**已提交**状态：打开申请，点击**取消申请**并确认。所有未完成的审批也会一并取消。
- **直接批准。** 显示*"直接批准，无需审批"*的申请没有审批人。
- **导入采购申请。** 在**采购申请**中点击**从 Excel 导入**，可为**草稿**申请添加明细。物品图片不会被导入，系统也不会自动提交。
