# 仪表盘

仪表盘是您登录后看到的第一个页面。它提供常用申请的快捷入口，并汇总与您角色相关的工作。

**不同角色看到的视图**

| 角色 | 仪表盘视图 |
| --- | --- |
| 所有人 | **我的工作** |
| 团队负责人、部门负责人、专业负责人，以及有下属的人员 | **我的团队**和**我的工作** |
| 人事、总经理、常务董事、系统管理员 | **概览**、**薪资与加班**和**运营**；如负责团队，还有**我的团队**；以及**我的工作** |

**入口位置**
- 侧边栏 → **仪表盘**（第一项）。登录后也会自动进入此页面。

---

## 快捷操作

仪表盘顶部的按钮可直接打开常用页面：

- **申请休假**
- **申请加班**
- **申请出差补贴**
- **申请机票**
- **审批中心**
- **我的资料**

您只会看到您的账户有权使用的申请按钮。

---

## 仪表盘视图

点击视图名称即可切换。刷新页面后，系统会保留当前打开的视图。

| 视图 | 显示内容 |
| --- | --- |
| **我的工作** | 您本人的事项，例如假期余额、加班、现场工作时间以及进行中的申请。 |
| **我的团队** | 您下属人员的汇总信息。 |
| **概览** | 面向人事和管理层的全公司汇总。 |
| **薪资与加班** | 全公司的薪资和加班数据。 |
| **运营** | 全公司的运营类申请和动态。 |

---

## 小贴士

- 显示的数据始终与您的角色权限一致。视图不会显示您在其他地方无权打开的记录。
- 使用快捷操作可以直接发起申请，无需经过**新建申请**。
