# 我的资料与通知

**我的资料**是您本人的员工档案，显示您的个人信息，以及假期、加班、考勤、工作时间表、文件、合同、薪酬、资产、差旅补贴和考核等标签页。您只能修改偏好设置、邮箱和密码。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 查看自己的资料和各标签页。修改语言、时区、日期格式、邮箱和密码。 |
| 人事 | 维护员工档案。员工仅可修改上述内容。 |

**入口位置**
- 侧边栏 → **我的资料**（位于侧边栏底部，您的姓名旁）。

---

## 资料标签页

| 标签页 | 显示内容 |
| --- | --- |
| 账户 | 您的姓名、员工信息及账户设置。 |
| 请假 | 您的假期余额和请假记录。您的现场派驻记录也在此处。 |
| 加班 | 您全年的加班情况（按类别）以及加班单记录。 |
| 考勤 | 您的月度考勤和标记日期。可在此提交说明。 |
| 工作时间表 | 您的工作时间表，以及未来 60 天内适用于您的公共假期。 |
| 文件 | 人事为您归档的文件。 |
| 合同 | 您的劳动合同信息。 |
| 工资单 | 您的工资单。您只能看到自己的。 |
| 资产 | 分配给您的公司资产。 |
| 差旅补贴 | 您的差旅补贴标准和申请。 |
| 考核 | 您的绩效考核。 |

---

## 如何修改偏好设置

1. 进入 **我的资料** → **账户**。
2. 修改**语言**、**时区**或**日期格式**，然后保存。

---

## 如何修改邮箱或密码

1. 进入 **我的资料** → **账户**。
2. **修改邮箱：** 输入新邮箱地址并保存。
3. **修改密码：** 输入当前密码，再两次输入新密码，然后保存。

---

## 通知

点击顶部栏的铃铛图标可查看通知，例如审批进展和公告。点击某条通知即可打开相关申请或页面。
