# 我的资料与通知

**我的资料**是您本人的员工档案，可以查看您的信息以及请假、加班、考勤、工作时间表、文件、合同、工资单、资产、差旅补贴和考核。您可以自行修改区域偏好、邮箱地址和密码，其他信息如需修改请联系人事。

---

## 如何打开个人资料

*（所有人）*

1. 在左侧菜单中，点击**我的资料**。它位于菜单底部，显示您的姓名。
2. 点击标签页查看相应内容。


| 标签页 | 显示内容 |
| --- | --- |
| **账户** | 您的姓名、员工信息和账户设置 |
| **请假** | 假期余额和请假记录，以及现场派驻 |
| **加班** | 本年度的加班情况，点击**查看全部**可查看所有加班单 |
| **考勤** | 月度考勤以及需要说明的日期 |
| **工作时间表** | 工作时间和即将到来的公共假期 |
| **文件** | 人事为您存档的文件 |
| **合同** | 您的劳动合同 |
| **资产** | 发放给您的公司设备 |
| **差旅补贴** | 差旅补贴标准和申请 |
| **考核** | 您的绩效考核 |

## 如何查看工资单

*（员工）*

1. 进入**我的资料** → **工资单**。您只能查看自己的工资单。
2. 每一行显示**期间**、**实发工资**和**发布日期**。标记为**未发布**的工资单仍在由人事准备中。
3. 点击**查看明细**，查看收入、加班、扣除和实发工资。
4. 点击**下载 PDF**，保存或打印工资单。

> **注意：** 如果显示 *"暂无工资单。人力资源部发布后会显示在这里。"*，说明人事尚未为您发布工资单。如认为缺少工资单，请联系人事。

## 如何修改语言、时区或日期格式

*（所有人）*

1. 进入**我的资料** → **账户**。
2. 在**区域偏好**中选择**语言**、**时区**和**日期格式**。留空则使用公司默认设置。
3. 点击**保存偏好**。

> **保存后：** 页面会提示*"偏好设置已保存。"*

> **注意：** 您也可以随时通过屏幕顶部的语言切换在中英文之间切换。

---

## 如何更改邮箱地址

*（所有人）*

1. 进入**我的资料** → **账户**。
2. 在**邮箱地址**中点击**更改邮箱**。
3. 填写**新邮箱地址**，点击**发送确认邮件**。
4. 打开新邮箱中的邮件，点击其中的链接。

> **发送后：** 在您点击链接之前，资料会显示*"待确认：[新邮箱]"*，原邮箱仍可正常使用。

如果资料显示**邮箱未验证**，请点击**重新发送激活邮件**，并使用邮件中的链接完成验证。

---

## 如何更改密码

*（所有人）*

1. 进入**我的资料** → **账户**。
2. 在**密码**中填写**当前密码**。
3. 填写**新密码**（至少 8 个字符），并在**确认新密码**中再输入一次。
4. 点击**更改密码**。

> **更改后：** 页面会提示*"密码已更改，其他会话已退出。"*请在其他设备上用新密码重新登录。

---

## 如何使用通知

*（所有人）*

有需要您处理或关注的事项时，您会收到通知，例如申请被批准或退回、有待您审批的事项，或有新公告发布。

1. 点击屏幕顶部的铃铛图标，数字表示未读数量。
2. 点击**未读**只看新通知，或点击**全部**。
3. 点击通知即可打开相关申请或页面。点击**标为已读**标记单条，或点击**全部标为已读**。
4. 点击**查看全部通知**打开完整列表。
