# 入门指南

欢迎使用施工企业 ERP。本手册按系统真实页面说明日常功能。

## 登录
1. 打开 **/login**，输入姓名与密码。
2. 邮箱未验证时，可在登录错误提示中使用**重新发送激活邮件**。
3. 新账号通过 **/activate?token=…** 设置密码后返回登录页。
4. 忘记密码请使用 **/forgot-password** 与 **/reset-password?token=…**。

## 首次登录
若要求修改密码，系统会先进入 **/change-password**，完成后再进入首页 **/**。

## 导航
- **侧栏** — 仅显示你有权限的模块（无 HR 权限时为精简菜单：仪表盘、新建申请、审批、考核收件箱、公告、我的资料）。
- **新建申请** — **/approvals/new** 打开可提交的表单列表。
- **使用手册** — 侧栏底部帮助图标会在新标签页打开本门户。

## 语言
主界面语言在 ERP 顶栏切换；本手册顶部另有 **EN / 中文** 切换。
