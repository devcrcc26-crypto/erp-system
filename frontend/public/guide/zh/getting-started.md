# 入门指南

欢迎使用施工企业 ERP。本页介绍如何登录、如何在系统中找到所需功能，以及申请与审批的基本流程。本手册的其他主题会逐步讲解各个模块。

**适用对象：** 所有人。

---

## 如何登录

1. 打开 ERP 登录页面。
2. 输入您的**姓名**（不是邮箱地址）和**密码**。
3. 点击**登录**。

**新账号？** 打开人事发送到您邮箱的激活链接，设置密码后再登录。

**忘记密码？** 点击登录页上的忘记密码链接，按邮件中的说明操作。

**邮箱尚未验证？** 登录提示中会提供**重新发送激活邮件**。点击后，打开新收到的邮件完成激活。

---

## 首次登录

如果人事为您设置了临时密码，系统会先要求您设置新密码，然后才能继续。完成后，您会进入**仪表盘**。

---

## 找到所需功能

| 区域 | 用途 |
| --- | --- |
| **左侧菜单** | 显示您可以使用的模块。您只能看到您的角色允许的内容。 |
| **新建申请** | 发起各类申请：请假、加班、差旅、报销、用章等。 |
| **审批** | 跟踪您自己的申请，并处理等待您审批的申请。 |
| **我的资料** | 您本人的档案：假期余额、加班、考勤、工资单、资产等。 |
| **铃铛图标**（右上角） | 您的通知，例如审批进展和公告。 |
| **使用手册** | 即本手册，会在新标签页中打开。 |

**左侧菜单显示的内容取决于您的角色：**
- **大多数员工**可以看到：仪表盘、新建申请、审批、我的考核收件箱、公告、费用报销、差旅补贴、我的资料和使用手册。
- **人事人员**还可以看到以下模块文件夹：**人员**、**考勤与假期**、**薪酬与差旅**和**运营**。

---

## 申请的基本流程

几乎所有申请都遵循相同的四个步骤：

1. **发起：** 点击左侧菜单中的**新建申请**，然后点击您需要的申请类型。
2. **填写：** 按步骤填写表单。在**审核并提交**中检查摘要，然后提交。
3. **审批：** 申请会按顺序发送给审批人，通常先是您的直属上级，然后是人事。您可以点击左侧菜单中的**审批**，然后点击**我的申请**，跟踪。
4. **结果：** 申请被批准、拒绝或退回时，您会收到通知。如果被退回，请按审批人的要求修改后重新提交。

完整的审批流程请参阅**审批**主题。
