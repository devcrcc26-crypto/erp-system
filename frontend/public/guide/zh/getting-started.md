# 入门指南

欢迎使用 Construction ERP。本页介绍如何登录、熟悉系统界面以及提交第一份申请。本指南的其他主题会逐步介绍系统的各个部分。

---

## 如何登录

*（所有人）*

1. 打开 ERP 登录页面。
2. **姓名**：填写您的全名，不是邮箱地址。
3. **Password**：填写密码。
4. 点击 **Sign in**（登录）。


> **注意：** 登录页面的部分文字目前只显示英文。

> **新账户：** 打开人事发送到您邮箱的激活链接，设置密码后登录。

> **注意：** 如果人事给了您临时密码，系统会要求您先设置新密码才能继续。

### 无法登录时

- **忘记密码：** 在登录页面点击 **Forgot password?**，然后按照邮件中的链接操作。
- **账户未激活：** 登录页面会显示 **Resend activation email**（重新发送激活邮件）。点击后使用新邮件中的链接。

## 如何熟悉界面

*（所有人）*

| 位置 | 用途 |
| --- | --- |
| **左侧菜单** | 您可以使用的系统功能。只显示您工作需要的内容。 |
| **新建申请** | 发起各类申请：请假、加班、出差、费用、用章等。 |
| **审批** | 跟踪您的申请，并处理等待您审批的申请。 |
| **我的资料** | 您本人的档案：假期余额、加班、考勤、工资单、资产等。 |
| **铃铛**（屏幕顶部） | 您的通知。 |
| **语言切换**（屏幕顶部） | 在中英文之间切换，本指南也会同步切换。 |
| **使用手册** | 本指南，位于左侧菜单中。 |

大多数员工可以看到**仪表板**、**新建申请**、**审批**、**公告**、**我的资料**和**使用手册**。团队负责人和学科负责人还可以看到**我的考核收件箱**。有员工向您汇报时，您还可以看到团队的请假、加班、考勤、现场派驻、考核、费用报销和差旅补贴。人事人员还可以看到**人员**、**考勤与假期**、**薪酬与差旅**和**运营**文件夹。

## 如何提交申请

*（员工）*

几乎所有申请的操作方式都相同。

1. 在左侧菜单中，进入**新建申请**。
2. 点击需要的申请类型。可以搜索或按分组筛选。
3. 按步骤填写表单，点击**下一步**继续。
4. 在**确认并提交**中核对所有信息，然后提交。

> **提交后：** 您的申请已发送审批。申请被批准或退回时，您会收到通知。

---

## 如何跟踪申请

*（员工）*

1. 在左侧菜单中，进入**审批** → **我的申请**。
2. 打开申请查看状态：**已提交**、**审核中**、**已批准**、**已退回**或**已拒绝**。

---

## 申请被退回时怎么办

*（员工）*

1. 打开退回通知，或在**审批** → **我的申请**中找到状态为**已退回**的申请。
2. 阅读横幅**此申请已退回**中审批人的备注。
3. 如需修改申请，点击申请顶部的**编辑**，修改后点击**保存**。页面会提示*"修改已保存。"*，并回到申请页面，状态仍为**已退回**。
4. 点击申请顶部的**重新提交**。在**重新提交申请**中，填写**给审批人的备注（可选）**，如有需要可上传文件，然后点击**重新提交**。

您只能编辑自己的申请，且仅限草稿或已退回状态。

完整的审批流程请参阅**审批**主题。
