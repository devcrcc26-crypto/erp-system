# 请假申请

使用请假申请来休假。表单只计算您的工作日，并在提交前显示这次申请会占用多少假期余额。

**找到与您相关的部分**

| 您的身份 | 请阅读 |
| --- | --- |
| 员工 | 如何申请休假、三个步骤、查看余额、跟踪申请、修改或取消申请，以及申请被退回时怎么办 |
| 团队负责人、部门负责人、专业负责人、总经理 | 如何批准、退回或拒绝请假申请，以及如何为团队成员申请休假 |
| 人事（人事经理、人事助理、人事专员） | 员工部分的全部内容，以及最后的人事部分 |

## 如何申请休假

*（员工）*

1. 在左侧菜单中，进入**新建申请**。
2. 点击**请假申请**，打开**新建请假申请**表单。表单分三步：**请假详情**、**附件材料**和**确认并提交**。


## 第 1 步 — 请假详情

*（员工）*

1. **假期类型**（必填）：选择**年假**、**病假**、**无薪假**、**产假**、**陪产假**、**紧急假**、**丧假**、**学习假**或**考试假**。只有档案中性别为女性的员工才会看到**产假**。
2. **请假时段**（至少一个，必填）：
   - 选择该时段的第一天和最后一天。
   - 选择**全天**、**上午**或**下午**。
   - 如需再加一段日期（例如分段请假），点击**添加时段**；如需删除，点击**删除**。
   - 时段不能重叠。
3. 查看每个时段下的天数。周末、公共假日和您的休息日按 0 天计算，半天按 ½ 天计算。如果某个时段没有工作日，表单会提示*"此范围内没有工作日"*。
4. 查看**假期余额**面板，其中显示**应享天数**、**结转天数**、**已用天数**、**待处理天数**、**剩余天数**和**提交后剩余**。您的假期年度从入职周年日开始计算，而不是从一月开始。
5. **原因**（选填）：说明请假原因。
6. 点击**下一步**。


> **注意：** **无薪假**不占用假期余额，这些天数按缺勤（无薪）处理。

## 第 2 步 — 附件材料

*（员工）*

1. 可选上传文件，例如病假的医疗证明。支持 PDF、JPG、PNG、DOC 或 DOCX 文件。
2. 点击**下一步**。

## 第 3 步 — 确认并提交

*（员工）*

1. 核对假期类型、日期、天数和附件。
2. 如需修改，点击**上一步**。
3. 点击**提交申请**。


> **提交后：** 您的申请已发送审批，状态为**已提交**。申请被批准或退回时，您会收到通知。除非申请被退回，否则您无需再做任何操作。

### 表单无法提交的原因

- *"所选日期的假期余额不足"*：申请天数超过了您的**剩余天数**。提示中会显示剩余天数和申请天数。
- *"时段不能重叠。"*：两个时段有重叠的日期。
- *"此范围内没有工作日"*：所选日期只包含周末、假日或休息日。
- 所选日期已被其他请假、现场派驻、居家办公或外勤占用，请选择其他日期。
- 所选日期不在您的在职期间内。

## 如何查看假期余额

*（员工）*

1. 在左侧菜单中，进入**我的资料**。
2. 点击**请假**标签页。**假期余额**部分会显示每种假期类型的已用和待处理天数。

填写请假表单时，表单右侧也会显示您的余额。


---

## 如何跟踪您的请假申请

*（员工）*

1. 在左侧菜单中，进入**我的资料**，点击**请假**标签页。
2. 在**请假记录**下，点击**查看全部**，查看所有申请。
3. 列表显示**申请编号**、**假期类型**、**开始日期**、**结束日期**、**天数**和**状态**。
4. 点击某条申请即可打开，查看日期、每日明细、原因、附件和**审批链**。

您也可以在**审批** → **我的申请**中跟踪任何申请。

**状态说明**

| 状态 | 含义 |
| --- | --- |
| 草稿 | 已保存，尚未发出。 |
| 已提交 | 已发送审批。 |
| 审批中 | 正在审批。 |
| 已退回 | 已退回给您修改。 |
| 已批准 | 已批准，天数从余额中扣除。 |
| 已拒绝 | 未获批准，申请已关闭。 |
| 已取消 | 已取消，待处理的天数已退回。 |

## 如何修改请假申请

*（员工 — 仅限状态为**草稿**或**已退回**时）*

1. 打开该申请（见*如何跟踪您的请假申请*）。
2. 点击**更新**。只有申请为**草稿**或**已退回**时才会显示此按钮。
3. 修改**假期类型**、**请假时段**或**原因**。规则与新申请相同。
4. 点击**保存**。

> **注意：** 保存不会改变状态（*"修改已保存。"*）。已退回的申请只有在您点击**重新提交**后才会重新送审。请见*申请被退回时怎么办*。

---

## 如何取消请假申请

*（员工 — 状态为**草稿**、**已提交**或**审批中**时）*

1. 打开该申请。
2. 点击**取消申请**。
3. 在**取消请假申请？**中确认。此操作无法撤销。

> **取消后：** 状态变为**已取消**，待处理的天数退回您的余额。已批准的请假不能由您取消，请联系人事。

---

## 申请被退回时怎么办

*（员工）*

申请被退回时，您会收到退回通知。打开申请即可查看原因。

1. 在左侧菜单中，进入**审批** → **我的申请**（或**待我处理**），打开状态为**已退回**的申请。横幅会显示**此申请已退回**以及审批人的备注。
2. 阅读备注。
3. 在同一页面点击**编辑**。修改**假期类型**、**请假时段**（可增删时段）或**原因**。天数会按工作日程自动计算，规则与新申请相同。
4. 点击**保存**。页面会提示*"修改已保存。"*，并回到申请页面，状态仍为**已退回**。 也可以从**我的资料** → **请假** → **查看全部**打开申请，点击**更新**后在那里保存，该表单顶部会显示审批人的备注。
5. 准备好后，点击申请顶部的**重新提交**（如无需修改，可跳过编辑）。在**重新提交申请**中，填写**给审批人的备注（可选）**，如有需要可上传文件，然后点击**重新提交**。

重新提交后，申请会从审批链的第一步重新开始，相应天数会再次从您的余额中预留。

## 如何批准、退回或拒绝请假申请

*（团队负责人、部门负责人、专业负责人、人事经理、总经理）*

请假申请转到您这里时，您会收到需要审批的通知。

1. 在左侧菜单中，进入**审批**，点击**待我处理**标签页。
2. 点击该请假申请，核对日期、每日明细、原因、附件和员工的**假期余额**。
3. 选择以下操作之一：
   - **批准**：点击**批准**，填写**备注（可选）**，再点击**批准**确认。
   - **退回**：点击**退回**，在**给提交人的备注**中写明需要修改的内容，再点击**退回**。员工会收到通知，可以修改后重新提交。
   - **拒绝**：点击**拒绝**，填写**拒绝原因**，再点击**拒绝**。申请将关闭，且无法撤销。员工会收到通知。
   - **有条件批准**：点击该按钮，填写**条件**，再点击**提交**。申请会停留在您的环节，直到条件解决。


> **决定后：** 如果还有下一位审批人，申请会转给他们。如果您是最后一位审批人，请假即获批准，天数从员工余额中扣除。

## 如何为团队成员申请休假

*（部门负责人限本部门、专业负责人限本专业、人事经理、总经理、常务董事）*

1. 在左侧菜单中，进入**新建申请**，点击**请假申请**。
2. 在**提交信息**中，打开**代其他员工提交**。
3. **员工**：按姓名或员工编号搜索并选择该员工。
4. 如果您是这份申请的审批人之一，可以勾选**自动审批我的环节**，在提交时自动批准您的环节。
5. 按*如何申请休假*中的三个步骤填写，然后点击**提交申请**。

> **提交后：** 申请归属于该员工，并按该员工自己的审批人审批。审计日志中会记录您为创建人。

## 如何查看所有请假申请

*（人事）*

1. 在左侧菜单中，进入**考勤与假期** → **请假申请**。
2. **请假申请**标签页显示所有申请。顶部统计显示**全部**、**草稿**、**待处理**、**已批准**和**已拒绝**。
3. 可按姓名或申请编号搜索，或按**假期类型**和**员工**筛选。点击**重置**清除筛选。
4. 点击某一行或**查看**，打开申请。
5. 如需下载列表，点击**导出 Excel**。只会导出符合当前搜索和筛选条件的记录。在窄屏上，该按钮位于 **⋯** 菜单中。

## 如何编辑或删除请假申请

*（人事）*

- **编辑：** 打开申请，点击**更新**。仅在申请为**草稿**或**已退回**时可用。修改后点击**保存更改**。
- **取消：** 打开申请，点击**取消申请**。仅在申请为**草稿**、**已提交**或**审批中**时可用。
- **删除：** 打开申请，点击**删除**，在**删除请假申请？**中确认。申请会从登记中移除，其对余额的影响会被回退；如果已批准，这些日期的考勤会重新计算。此操作无法撤销。

## 如何查看和调整假期余额

*（人事）*

1. 进入**考勤与假期** → **请假申请**，点击**假期余额**标签页。
2. 顶部统计显示**员工数**、**余额不足**和**有待审批**。可按姓名或员工编号搜索，或选择**年份**。
3. 如需修改余额，点击该员工行上的**编辑余额**，打开**设置假期余额**窗口。
4. **假期年度**（必填）：选择年度。当前假期年度从员工的入职周年日开始。
5. 为每种**假期类型**填写**应享天数**和**已用天数**（以 0.5 天为单位）。**结转天数**只适用于年假。**剩余天数**会自动计算：应享天数 + 结转天数 − 已用天数 − 待处理天数。
6. **原因**（必填，至少 3 个字符）：说明修改余额的原因。
7. 点击**保存**。修改会记录在员工的**余额记录**中。

## 如何从 Excel 导入请假申请

*（人事）*

1. 进入**考勤与假期** → **请假申请**，点击**从 Excel 导入**。
2. **上传**：点击**下载模板**，保持表头行不变。每条申请填写一行：**employeeEmail**（如邮箱为空则填写 **employeeId**）、**leaveType**、**startDate**、**endDate**、**days**，以及选填的 **reason**。
3. 将 .xlsx 文件拖放到上传区域，或点击选择文件。
4. **审核**：每一行会被标记为**就绪**、**警告**、**无效**、**重复**或**文件内重复**。缺少某一列时会停止检查，提示中会写明缺少的列。请在文件中修正无效行，然后点击**选择其他文件**重新上传。
5. 点击**导入 N 行**。

> **导入后：** 每一行都会以该员工的名义提交为请假申请，规则和审批人与员工本人提交时相同。

## 人事须知

*（人事）*

- **假期年度按入职周年日拆分。** 如果申请跨越员工的入职周年日，每一天会计入其所在的假期年度。
- **没有余额记录。** 如果表单提示*"暂无余额记录 - 请联系人力资源"*，请在**假期余额**标签页中为该员工设置余额。
- **在职期间以外的日期。** 不能为员工入职前或离职后的日期申请休假。
- **申请休假时不检查考勤。** 考勤打卡在月末后才导入，因此不会阻止请假申请。
