# 请假申请

请假申请用于休假，包括年假、病假、无薪假等各类假期。填写表单时，系统会根据您的假期余额和工作时间表进行核算，提交前您就能知道该申请会占用多少天。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 申请休假、查看余额、跟踪申请，并在允许时编辑或取消申请。 |
| 团队负责人、部门负责人、专业负责人 | 在**审批**中审批团队成员的请假。部门负责人和专业负责人还可以为本部门或本专业的人员代为提交请假。 |
| 人事（人事经理、人事助理、人事专员） | 查看所有请假申请、调整余额、取消已批准的请假，以及删除申请。 |
| 总经理、常务董事、系统管理员 | 您本人的请假在提交后立即批准。 |

**入口位置**
- 申请休假：点击左侧菜单中的**新建申请**，然后点击**请假**。
- 您的余额和记录：点击左侧菜单中的**我的资料**，然后点击**请假**。点击**查看全部**可查看完整记录。
- 所有申请和余额（仅人事）：点击左侧菜单中的**考勤与假期**，然后点击**请假申请**。

---

## 如何申请休假

1. 点击左侧菜单中的**新建申请**，然后点击**请假**。
2. 选择**假期类型**：年假、病假、无薪假、产假、陪产假、紧急假、丧假、学习假或考试假。产假仅对档案性别为女性的员工显示。
3. 添加**请假时段**：
   - 为每个时段选择**日期范围**。
   - 设置**天数类型**：*全天*、*上午*或*下午*。
   - 点击**添加时段**可增加另一段日期，例如分段请假。时段之间不能重叠。
4. 查看**提交后剩余**。系统只按您的工作时间表计算工作日，周末、公共假日和非工作日不计入，预览中会列出被排除的日期。
5. 如有需要，填写**原因**。
6. 点击**下一步**。
7. **附件材料：** 如有需要可上传文件（PDF、JPG、PNG、DOC 或 DOCX）。病假如有医疗证明，请一并上传。
8. 点击**下一步**，在**确认并提交**中核对摘要，然后点击**提交申请**。

> **接下来会发生什么：** 申请发送给您的审批人（见下文*审批流程*），并打开申请详情页。如果您的角色无需审批，请假会立即批准并记录。

### 申请可能无法提交的原因

- **余额不足。** 申请天数超过您的**剩余天数**时，表单会显示*"所选日期的假期余额不足"*并列出相关数字。无薪假没有余额，不会因此被阻止。
- **没有工作日。** 所选日期只包含周末或公共假日。
- **时段重叠。** 同一申请中的两个时段相互重叠。
- **日期已被占用。** 全天请假不能与已批准或待审批的请假、现场派驻、居家办公或外勤重叠。半天请假只会被现场派驻、居家办公或外勤阻止，因此两个半天假可以相邻。

---

## 如何查看假期余额

1. 点击左侧菜单中的**新建申请**，然后点击**请假**。右侧的**假期余额**面板会随所选日期更新。
2. 面板显示所选假期类型的以下数据：
   - **应享天数**：本假期年度您可享有的天数。
   - **结转天数**：从上一年度结转的天数。
   - **已用天数**：已批准并已休的天数。
   - **待处理天数**：仍在等待审批的申请所占用的天数。
   - **剩余天数**：应享天数 + 结转天数 − 已用天数 − 待处理天数。
3. 假期年度从您的**入职周年日**起算，而不是从一月起算。面板会标明当前使用的年度。

您也可以随时点击左侧菜单中的**我的资料**，然后点击**请假**，查看余额。

> **注意：** 无薪假没有余额，面板会注明这一点。

---

## 如何跟踪您的请假申请

1. 点击左侧菜单中的**我的资料**，然后点击**请假**，点击**查看全部**。
2. 点击某条申请打开详情页。详情页显示日期、天数、时段、原因、附件、申请时的余额以及审批流程。

您也可以点击左侧菜单中的**审批**，然后点击**我的申请**，跟踪任何申请。

---

## 如何编辑请假申请

*（申请人，在申请为草稿或已退回时；人事也可编辑）*

1. 打开该申请。
2. 点击**更新**（铅笔按钮）。只有申请为**草稿**或**已退回**时才会显示。
3. 修改假期类型、时段、天数类型或原因。检查规则与新申请相同。
4. 点击**保存更改**。

> **接下来会发生什么：** 修改会被保存，状态保持不变。保存**已退回**的申请不会把它重新送审，请见下文*如何处理被退回的申请*。**已提交**、**审批中**、**已批准**、**已拒绝**或**已取消**的申请无法编辑。如需修改，请在允许时取消该申请，然后重新提交。

---

## 如何取消请假申请

*（申请人或人事）*

1. 打开该申请。
2. 点击**取消申请**。
3. 确认。弹窗会提示此操作无法撤销。

> **接下来会发生什么：** 申请变为**已取消**，待处理的天数退回余额，关联的审批也会被取消。
>
> **谁可以取消哪些申请：**
> - **草稿**、**已提交**或**审批中**：申请人或人事。
> - **已批准**：仅人事。天数会退回余额，并重新计算这些日期的考勤。
> - **已拒绝**、**已退回**或已经**已取消**：无法取消。

---

## 如何处理被退回的申请

*（申请人）*

1. 您会收到*"审批已退回"*通知，申请显示**已退回**，并附有审批人的备注。
2. 打开该申请，点击**更新**，完成修改后点击**保存更改**。
3. 打开**审批**，找到该申请，在**重新提交**面板中填写简短说明并添加所需文件，然后点击**重新提交**。

> **接下来会发生什么：** 申请从第一位审批人重新开始，该审批人会收到*"已重新提交，待审批"*通知。仅保存修改不会重新提交。

---

## 如何为他人提交请假

*（人事经理、总经理、常务董事、系统管理员；部门负责人限本部门；专业负责人限本专业）*

1. 点击左侧菜单中的**新建申请**，然后点击**请假**。
2. 在**提交信息**中，打开**代其他员工提交**，并选择该员工。
3. 按正常方式填写并提交。

> **接下来会发生什么：** 申请归属于该员工，审批流程依据该员工的上级建立，而不是您本人。

---

## 人事如何管理请假

*（仅人事）*

1. 点击左侧菜单中的**考勤与假期**，然后点击**请假申请**。
2. 在**申请**标签页查看所有申请。可按**员工**、**假期类型**或**状态**筛选，或按申请编号搜索。
3. 在**余额**标签页查看每位员工按假期类型和年度的余额。
4. 点击**编辑余额**调整余额（期初余额、调整或快照）。每次修改都会记录在余额历史中。
5. 如需删除申请，打开申请，点击**删除**（垃圾桶按钮）并确认。其对余额的影响会被回退。

---

## 审批流程

审批人在**审批**中处理。详情请参阅**审批**主题。

| 申请人 | 审批人（按顺序） |
| --- | --- |
| 员工 | **汇报对象（直属上级）**，然后**人事经理** |
| 专业负责人 | **部门负责人**（如有），然后**人事经理** |
| 部门负责人 | **总经理**，然后**人事经理** |
| 人事人员 | **人事经理** |
| 人事经理 | **总经理** |
| 总经理、常务董事、系统管理员 | 无需审批，提交即批准 |

最后一位审批人批准后，申请变为**已批准**，天数从*待处理*转为*已用*。

**状态说明**

| 状态 | 含义 |
| --- | --- |
| 草稿 | 已保存，尚未发出。 |
| 已提交 | 已发出，等待第一位审批人。 |
| 审批中 | 审批人正在审阅。 |
| 已退回 | 已退回给您修改。 |
| 已批准 | 已完全批准，天数计为已用。 |
| 已拒绝 | 申请被拒绝，流程结束。 |
| 已取消 | 由申请人或人事取消。 |

---

## 小贴士

- 尽早提交请假，给审批人留出处理时间。
- 提交前先查看**提交后剩余**。
- 如果申请长时间没有进展，请打开申请查看审批流程，确认当前在等待哪位审批人。
