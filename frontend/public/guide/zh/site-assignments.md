# 现场派驻

现场派驻记录您在项目现场（而非日常工作地点）工作的日期。您提交现场、事由和日期范围。获批后，这些日期会用于差旅补贴和加班。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 申请自己的现场派驻，并在**我的资料** → **请假**中查看。 |
| 审批人 | 审批在**审批**中转到您这里的申请。 |
| 人事及请假负责人员 | 在**考勤与假期** → **现场派驻**中查看全部派驻记录，并可为其他员工提交申请。 |

**入口位置**
- 申请：**新建申请** → **现场派驻**。
- 您的派驻记录：侧边栏 → **我的资料** → **请假**。
- 人事列表：侧边栏 → **考勤与假期** → **现场派驻**（仅人事及请假负责人员可见）。

---

## 如何申请现场派驻

1. 进入 **新建申请** → **现场派驻**。
2. **代他人提交（可选）：** 人事可以选择其他员工。
3. 填写**现场**或**项目**，以及**事由**。
4. 添加一个或多个**日期范围**。
5. 如表单要求，填写**补录原因**。在月份结束后补录时必须填写。
6. 点击**审核并提交**，检查详情后提交。

> **接下来会发生什么：** 申请进入审批流程。您可以在**审批**中跟踪。

---

## 对加班的影响

现场派驻日不受工作日午餐时段加班限制的影响，因此外勤日可以使用完整的可选加班时段。

---

## 小贴士

- 请按照现场工作的实际日期填写。差旅补贴和加班都会使用这些日期。
- 如果是事后补录，请在提交时填写补录原因，否则表单无法提交。
