# 加班申请

您每个月使用一张加班表记录加班。每次加班添加一条记录，月底一次性提交审批。系统会自动把工时分为平时加班、晚间加班、周末加班和节假日加班。

**找到与您相关的部分**

| 您的身份 | 请阅读 |
| --- | --- |
| 员工 | 打开加班表、添加记录、提交、修改、取消、跟踪加班表，以及加班表被退回时怎么办 |
| 团队负责人、部门负责人、专业负责人、人事经理、总经理 | 如何批准、退回或拒绝加班表，以及如何为团队成员填报加班 |
| 人事（人事经理、人事助理、人事专员） | 以上全部内容，以及最后的人事部分 |

---

## 先了解这些规则

*（所有填报加班的人）*

- 只有**正常工作时间以外**的时间才计为加班。如果所选时间在排班内，会提示*"这些时间在您的正常工作时间内。"*
- 周一至周五的 **12:30–13:30 是午餐时间**，不计为加班。
- 当天如有**已批准的请假**，请假覆盖的时间不能申报加班。
- 在**已批准的现场派驻**日，全天工时都可以申报。表单会显示*"现场派驻日 — 全天工时均可计加班（不适用常规定班）。"*
- **不能打开未来月份的加班表**，也不能填写尚未发生的日期。
- 每条记录必须在**同一天**内。如果工作超过午夜，第一条记录在 24:00 结束，再在次日添加一条从 00:00 开始的记录。
- 同一天的两条记录不能重叠。
- 该月工资核算定稿后，加班表会显示*"此加班已锁定在当前工资核算中，无法编辑"*，任何内容都不能再修改。

## 如何打开加班表

*（员工）*

1. 在左侧菜单中，进入**新建申请**。
2. 点击**加班申请**，打开**本月加班表**页面。
3. 页面只显示**当前月份**。员工不能打开往月加班表。（代他人填报的人事/主管仍可选择往月。）
4. 点击**打开工时表**。
   - 如果本月已有草稿，页面会提示您，请点击**继续编辑草稿**。
   - 如果本月的加班表已提交，请点击**打开**。


> **打开后：** 加班表以**草稿**状态打开，接下来添加记录。

---

## 如何添加加班记录

*（员工）*

1. 在加班表中，点击**添加记录**。
2. **日期**（必填）：选择该月内、不是未来的日期。
3. **开始**和**结束**（必填）：选择时间。列表只显示当天可以计为加班的时间。如果没有可选时间，会提示*"当天没有可选的加班时段。"*
4. 如果工作超过午夜，点击**添加次日记录**，在次日添加剩余时间。
5. **工作内容**（必填）：描述您做了什么工作。
6. 查看**工时预览**，其中显示**平时加班**、**晚间加班**（22:00–06:00）、**周末加班**、**节假日加班**和**合计**。
7. 点击**保存**。


> **保存后：** 记录会出现在**加班记录**中，合计随之更新。如果某条记录显示**考勤核对**，说明时间与您当天的考勤打卡不一致。您仍然可以保存和提交。

---

## 如何为加班表添加附件

*（员工）*

1. 打开您的加班表。
2. 在**附件**下，点击**添加附件**并选择文件，例如签字的考勤记录。
3. 如需移除文件，点击文件旁的**删除**并确认。

---

## 如何提交加班表

*（员工）*

1. 打开您的加班表。表中至少要有一条记录。
2. 点击**提交表单**。
3. 在**提交加班表？**中确认。


> **提交后：** 您的加班表已发送审批，状态为**已提交**。加班表被批准或退回时，您会收到通知。除非被退回，否则您无需再做任何操作。

---

## 如何修改加班表

*（员工）*

1. 打开您的加班表（见*如何跟踪您的加班表*）。
2. 在要修改的记录上，点击 **⋯** → **更新**。如需添加其他日期，点击**添加记录**。
3. 修改后点击**保存**。

- **草稿**或**已退回**的加班表：修改会被保存，准备好后再提交。
- **已提交**或**已批准**的加班表：在该月工资核算锁定前仍可修改。保存后会提示*"您的加班申请已更新并重新提交审批"*，加班表会从头重新审批。
- **已被工资核算锁定**：无法修改。

---

## 如何取消加班表

*（员工 — 状态为**草稿**或**已提交**时）*

1. 打开您的加班表。
2. 点击**取消表单**。
3. 在**取消加班表？**中确认。加班表及其审批申请都会被取消。

---

## 如何跟踪您的加班表

*（员工）*

1. 在左侧菜单中，进入**我的资料**，点击**加班**标签页。
2. **本年度加班**显示您的平时、晚间、周末和节假日加班时数。修改**年份**可查看其他年份。
3. 在**加班记录**下，点击**查看全部**，查看每张加班表的**表单编号**、**周期**、各类工时、**合计（小时）**和**状态**。
4. 点击某张加班表即可打开。

**状态说明**

| 状态 | 含义 |
| --- | --- |
| 草稿 | 您还在添加记录。 |
| 已提交 | 已发送审批。 |
| 审批中 | 正在审批。 |
| 已退回 | 已退回给您修改。 |
| 已批准 | 已批准。 |
| 已拒绝 | 未获批准，加班表已关闭。 |
| 已取消 | 已取消。 |

**已重新提交**标记表示加班表修改后已重新送审。

---

## 加班表被退回时怎么办

*（员工）*

加班表被退回时，您会收到退回通知。打开加班表即可查看原因。

1. 在左侧菜单中，进入**审批** → **待我处理**（或**我的申请**），打开状态为**已退回**的加班表。横幅会显示**此申请已退回**以及审批人的备注。
2. 阅读备注。
3. 用以下任一方式打开加班表：
   - 在同一申请页面，点击顶部的**编辑**，或加班表摘要中的**更新**。
   - 或进入**我的资料** → **加班**，点击**查看全部**，再点击该加班表。
4. 按要求修改记录，然后点击**保存**。
5. 点击**提交表单**并确认。加班表会从审批链的第一步重新开始。

> **注意：** 加班申请在**审批**中没有**重新提交**按钮。重新提交加班表即为重新送审，同时会更新加班表合计。

## 如何批准、退回或拒绝加班表

*（团队负责人、部门负责人、专业负责人、人事经理、总经理）*

加班表转到您这里时，您会收到需要审批的通知。

1. 在左侧菜单中，进入**审批**，点击**待我处理**标签页。
2. 点击该加班表，核对每条记录的**日期**、**时间**、**工时**和**工作内容**，以及合计。
3. 决定前请注意：
   - 记录上的**考勤核对**：时间与员工的考勤打卡不一致。
   - 提示加班表中有未登记在公共假期日历中的手动标记假日的横幅：请核实这些日期。
   - **已编辑**和**此申请在批准后被编辑过**：员工在之前批准后修改过加班表。表格会以**变更前**和**变更后**显示每项改动。
4. 选择以下操作之一：
   - **批准**：点击**批准**，填写**备注（可选）**，再点击**批准**。
   - **退回**：点击**退回**，填写**给提交人的备注**，再点击**退回**。员工会收到通知，可以修改后重新提交。
   - **拒绝**：点击**拒绝**，填写**拒绝原因**，再点击**拒绝**。加班表将关闭，且无法撤销。
   - **有条件批准**：填写**条件**，点击**提交**。

## 如何为团队成员填报加班

*（部门负责人、专业负责人、人事）*

1. 在左侧菜单中，进入**新建申请**，点击**加班申请**。
2. 选择**月份**和您要为其填报的**员工**。
3. 点击**打开工时表**，添加记录，然后点击**提交表单**，步骤同上。

加班表归属于该员工，并按该员工自己的审批人审批。

## 如何查看所有加班表

*（人事）*

1. 在左侧菜单中，进入**考勤与假期** → **加班申请**，打开**加班表**列表。
2. 顶部统计显示**全部**、**待处理**、**已批准**和**已拒绝**。
3. 可按表单编号搜索，或按**员工**、**月份**和**年份**筛选。点击**重置**清除筛选。
4. 列表显示**表单编号**、**员工**、**周期**、**平时加班（小时）**、**晚间加班（小时）**、**周末（小时）**、**节假日（小时）**、**合计（小时）**和**状态**。
5. 点击某张加班表即可打开。

## 如何修改或删除加班

*（人事经理）*

- **修改记录：** 打开加班表，在记录上点击 **⋯** → **更新**，修改后点击**保存**。
- **删除记录：** 在记录上点击 **⋯** → **删除**，在**删除记录？**中确认。合计会重新计算。
- **删除加班表：** 打开加班表，点击**删除**，在**删除加班表？**中确认。加班表将被移除，其审批申请会被取消。此操作无法撤销。

## 如何从 Excel 导入加班

*（人事经理、总经理、常务董事）*

1. 进入**考勤与假期** → **加班申请**，点击**从 Excel 导入**，为多名员工导入。如只导入到某一张加班表，请打开该表后在表内点击**从 Excel 导入**。
2. **上传**：点击**下载模板**，保持表头行不变。每条记录填写一行：**employeeEmail** 或 **employeeId**、**date**、**startTime**、**endTime**、**taskDescription**，如果当天是假日，再填写 **isHoliday**。
3. 将 .xlsx 文件拖放到上传区域。文件最大 5 MB、500 行。
4. **审核**：检查标记为**就绪**和**无效**的行。如有无效行，请修正后重新上传。
5. 点击**导入 N 行**。

> **注意：** 只能导入到**草稿**或**已退回**状态的加班表。

## 人事须知

*（人事）*

- **工资核算锁定。** 该月工资核算定稿后，任何人都不能再修改该月的加班。
- **手动标记的假日。** 如果导入或填写的某天被标记为假日，但不在公共假期日历中，审批人会看到提示。如果确实是假日，请在**考勤与假期** → **公共假期**中添加。
- **批准后修改。** 如果员工修改了已批准的加班表，会重新审批，审批人可以看到具体改动。
