# 加班申请

加班按**月度加班表**记录。您为当月打开一张加班表，每次加班添加一条记录，然后提交审批。系统会自动将工时划分为平时、晚间、周末和节假日等类别，并实时更新合计。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 打开当月加班表、添加记录、提交并跟踪审批。 |
| 审批人 | 在**审批**中批准、退回或拒绝加班表。 |
| 人事（人事经理、人事助理、人事专员） | 查看所有加班表、编辑或删除记录、从 Excel 导入加班，以及删除加班表。 |

**入口位置**
- 打开加班表：点击左侧菜单中的**新建申请**，然后点击**加班**。
- 您的加班和历史：点击左侧菜单中的**我的资料**，然后点击**加班**。点击**查看全部**可打开您的任意一张加班表。
- 所有加班表（仅人事）：点击左侧菜单中的**考勤与假期**，然后点击**加班申请**。

---

## 先了解这些规则

- **只有排班时间之外的时间才计为加班。** 您排定的工作时间内的时间不算加班；班前、班后、周末和公共假日的时间才算。
- **工作日午餐时间不计加班。** 周一至周五的 12:30–13:30 会被排除。表单会显示*"午餐休息（12:30–13:30）不计为加班"*。周六、周日、公共假日和现场派驻日不受影响。
- **已批准的请假会扣除相应工时。** 当天如有已批准的请假，请假覆盖的时间不能申报加班。半天假只排除对应的半天。
- **现场派驻日例外。** 在已批准的现场派驻日，您正常排班的工时也可以申报为加班。
- **不能填写未来日期。** 不能为尚未发生的日期录入加班，也不能打开未来月份的加班表。
- **必须在当月之内。** 每条记录的日期必须在该加班表所属月份内。
- **不能重叠。** 同一天的两条记录不能在时间上重叠。
- **工资核算后锁定。** 该月工资核算定稿后，加班表会显示*"此加班已锁定在当前工资核算中，无法编辑"*。

---

## 如何打开加班表

1. 点击左侧菜单中的**新建申请**，然后点击**加班**。
2. **选择月份**：选择您加班的月份，可以选择往月。
3. 点击**打开工时表**。
   - 如果该月已有草稿，点击**继续编辑草稿**。
   - 如果该月的加班表已提交，点击**打开**。

> **接下来会发生什么：** 加班表以**草稿**状态打开，可以开始添加记录。

---

## 如何添加加班记录

1. 在加班表中点击**添加记录**。跨过午夜的夜班请使用次日记录选项。
2. 选择**日期**。
3. 选择**开始**和**结束**时间。时间选择器只提供当天可计为加班的时段。如果没有可选时段，表单会提示*"当天没有可选的加班时段。"*
4. 填写**工作内容**，即您加班时做了什么。此项必填。
5. 如有支持材料可上传，例如签字的考勤记录（PDF、图片、Word 或 Excel）。
6. 查看工时预览：
   - **平时加班**：工作日排班之外的工时（*平时 × 1.5*）。
   - **晚间加班**：22:00–06:00（*晚间 × 1.75*）。
   - **周末加班**（*周末 × 2.0*）。
   - **节假日加班**（*节假日 × 2.5*）。
   - **合计**：所有类别之和。
7. 点击**保存**。

> **接下来会发生什么：** 记录被添加，合计随之更新。如果时间与您的考勤打卡不一致，记录会显示**考勤核对**标记。该标记仅为提醒，不会阻止保存。

---

## 如何提交加班表

1. 打开您的加班表。加班表必须为**草稿**或**已退回**，且至少有一条记录。
2. 点击**提交表单**并确认。

> **接下来会发生什么：** 加班表变为**已提交**并发送给您的审批人。如果您的角色无需审批，会立即批准。重新提交**已退回**的加班表时，会回到第一位审批人。

---

## 如何修改加班表

- **草稿或已退回：** 打开记录，修改日期、时间、工作内容或附件，然后点击**保存**。不影响审批。
- **已提交或已批准：** 在该月工资核算锁定之前，您仍可以编辑记录。保存后，审批会**从第一位审批人重新开始**，您会收到*"您的加班申请已更新并重新提交审批"*。审批人可以看到自上次批准以来的变更。
- **已被工资核算锁定：** 无法再修改。

---

## 如何取消加班表

1. 在加班表为**草稿**或**已提交**时打开它。
2. 点击**取消表单**并确认。关联的审批也会被取消。

**已批准**、**已拒绝**或**已退回**的加班表无法取消。

---

## 人事如何管理加班

*（仅人事）*

- **查看所有加班表：** 点击左侧菜单中的**考勤与假期**，然后点击**加班申请**。使用顶部统计（**全部**、**待处理**、**已批准**、**已拒绝**）并可按表单编号搜索。
- **删除记录：** 打开加班表，点击记录上的**删除**并确认。合计会重新计算。
- **删除加班表：** 打开加班表，点击**删除**并确认。该加班表将被永久删除，其审批也会被取消。
- **从 Excel 导入：**
  1. 在列表上（跨多张加班表）或在某张加班表内（仅该表）点击**从 Excel 导入**。
  2. 点击**下载模板**，保持表头行不变。
  3. 每条记录填写一行：员工邮箱或编号、日期、开始时间、结束时间和工作内容。
  4. 上传 `.xlsx` 文件（不超过 5 MB、500 行）。
  5. 检查**就绪**和**无效**的行，修正无效行后确认导入。

  只能导入到**草稿**或**已退回**状态的加班表。

## 审批流程

加班的审批顺序与请假相同：

| 申请人 | 审批人（按顺序） |
| --- | --- |
| 员工 | **汇报对象（直属上级）**，然后**人事经理** |
| 专业负责人 | **部门负责人**（如有），然后**人事经理** |
| 部门负责人 | **总经理**，然后**人事经理** |
| 人事人员 | **人事经理** |
| 人事经理 | **总经理** |
| 总经理、常务董事、系统管理员 | 无需审批，提交即批准 |

**状态说明**

| 状态 | 含义 |
| --- | --- |
| 草稿 | 正在填写。 |
| 已提交 | 已发出审批。此时编辑会重新开始审批。 |
| 已退回 | 已退回给您。修改后再次点击**提交表单**。 |
| 已批准 | 已完全批准。在工资核算锁定前编辑会重新开始审批。 |
| 已拒绝 | 申请被拒绝，流程结束。 |
| 已取消 | 由您或人事取消。 |

---

## 小贴士

- 尽量在当天或次日录入加班，时间更准确。
- 保存前查看工时预览。
- 如果出现**考勤核对**标记，提交前请对照您的考勤记录核实时间。
- 建议在月底所有记录添加完毕后，一次性提交加班表。
