# 设备和材料退出许可

出入证用于记录离开或进入现场的设备和材料。您逐项列出物品，然后提交审批。获批的出入证会打印出来交给门岗，供保安逐项核对。

**找到与您相关的部分**

| 您的身份 | 请阅读 |
| --- | --- |
| 员工 | 申请出入证、跟踪出入证，以及出入证被退回时怎么办 |
| 出入证审批人 | 如何审批出入证 |
| 人事及行政人员 | 查看所有出入证、出入门证和门岗登记 |

## 如何申请出入证

*（员工）*

1. 在左侧菜单中，进入**新建申请**。
2. 点击**出入证**。表单分三步：**申请详情**、**物品清单**和**确认并提交**。


## 第 1 步 — 申请详情

*（员工）*

1. **方向**（必填）：物品离开现场选**出场**，进入现场选**入场**。
2. **日期**（必填）：今天或之后的日期。
3. **部门**（选填）。
4. 点击**下一步**。

## 第 2 步 — 物品清单

*（员工）*

1. 点击**添加物品**，为每件物品填写：
   - **物品名称**（必填）
   - **问题**：物品用途或状况
   - **数量**（必填）和**单位**
   - **物品图片**（选填）：JPEG、PNG、WebP 或 GIF 照片
2. 点击**保存**添加物品。至少添加一件物品。
3. 点击**下一步**。


## 第 3 步 — 确认并提交

*（员工）*

1. 核对方向、日期和物品。
2. 如有需要，上传**附件材料**。
3. 如需修改，点击**上一步**。
4. 点击**提交申请**。

> **提交后：** 页面会提示*"出入证已提交审批"*。您的出入证已发送审批。出入证被批准或退回时，您会收到通知。

---

## 如何跟踪您的出入证

*（员工）*

1. 在左侧菜单中，进入**审批** → **我的申请**，打开该出入证。
2. 您可以看到物品、状态和**审批链**。

---

## 出入证被退回时怎么办

*（员工）*

出入证被退回时，您会收到退回通知。打开出入证即可查看原因。

1. 在左侧菜单中，进入**审批** → **我的申请**，打开状态为**已退回**的出入证。横幅会显示**此申请已退回**以及审批人的备注。
2. 阅读备注。
3. 如需修改出入证，点击出入证顶部的**编辑**（或在**我的申请**列表中该出入证旁的**编辑**）。表单会带出您之前填写的内容，审批人的备注显示在顶部。修改后点击**保存**。页面会提示*"修改已保存。"*，并回到申请页面，状态仍为**已退回**。可修改基本信息和物品（包括物品图片）。
4. 准备好后，点击申请顶部的**重新提交**（如无需修改，可跳过编辑）。在**重新提交申请**中，填写**给审批人的备注（可选）**，如有需要点击**添加附件**，然后点击**重新提交**。

重新提交后，出入证会从审批链的第一步重新开始。

> **重新提交后：** 页面会提示*"申请已重新提交"*。

> **注意：** 编辑表单不能添加证明文件。如需发送，请在点击**重新提交**时添加。

## 如何审批出入证

*（出入证审批人）*

出入证转到您这里时，您会收到需要审批的通知。

1. 在左侧菜单中，进入**审批** → **待我处理**，打开该出入证。
2. 核对方向、日期以及每件物品的名称、数量和照片。
3. 选择**批准**、**退回**（填写**给提交人的备注**）或**拒绝**（填写**拒绝原因**）。提交人会收到通知。

## 如何查看所有出入证

*（人事及行政人员）*

1. 在左侧菜单中，进入**运营** → **设备和材料退出许可**，打开**设备材料出入证**。
2. 顶部统计显示**全部**、**草稿**、**待处理**、**已批准**和**已拒绝**。
3. 可按申请编号、员工或部门搜索，或按员工筛选。
4. 列表显示**申请编号**、**员工**、**代提**、**方向**、**日期**、**部门**、**物品数**、**状态**和**当前层级**。
5. 点击某张出入证即可打开。

## 如何打印出入门证或门岗登记

*（人事及行政人员）*

- **单张出入证：** 打开已批准的出入证，点击**出入门证**。
- **某一天的所有出入证：** 在列表中点击**门岗通行证登记**，选择**日期**和**方向**（**入场与出场**、**入场**或**出场**），然后点击**下载 PDF**。PDF 会列出每件物品，并留有供保安核对的栏目。


> **下载后：** 页面会提示*"门岗登记 PDF 已下载。"*请将其张贴在门岗。

## 人事须知

*（人事及行政人员）*

- **代他人提交的出入证**至少需要一位审批人。
- **取消。** 员工、人事或具有全部权限的角色可以在出入证为**草稿**或**已提交**时取消：打开出入证，点击**取消申请**，并在**取消出入证？**中确认。
- **直接批准。** 显示*"直接批准，无需审批"*的出入证没有审批人。
