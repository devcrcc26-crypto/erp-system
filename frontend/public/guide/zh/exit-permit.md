# 设备和材料退出许可

退出许可用于记录离开或返回现场的设备和材料。您逐条列出物品及数量与单位，可选附上每件物品的照片和证明文件，然后提交审批。审批通过的许可在门岗使用。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 为您运送的物品提交退出许可；如果被允许代他人提交，也可以为他人提交。在**审批**中跟踪。 |
| 审批人 | 审批在**审批**中转到您这里的许可。 |
| 人事及行政人员 | 在**运营** → **行政** → **设备和材料退出许可**中查看全部许可并处理。 |

**入口位置**
- 提交：**新建申请** → **退出许可**（或打开 `/approvals/new/equipment-and-materials-exit-permit`）。
- 人事列表：侧边栏 → **运营** → **行政** → **设备和材料退出许可**（仅人事及行政人员可见）。

---

## 如何提交退出许可

1. 进入 **新建申请** → **退出许可**。
2. **申请详情：**
   - 选择**方向**（物品离开现场还是返回现场）。
   - 可选填**日期**、**部门**，以及**代表**的员工（即许可代为办理的对象）。
3. **物品：** 点击**添加物品**，每条填写：
   - **物品名称**
   - **事由**
   - **数量**和**单位**
   - **物品照片**（可选）：JPEG、PNG、WebP 或 GIF 格式
   - 点击**保存**加入列表。使用**编辑物品**可修改。
4. **证明文件：** 可选附上相关文件。
5. 点击**审核并提交**，检查摘要后点击**提交申请**。

> **接下来会发生什么：** 许可进入审批流程，您可以在**审批**中跟踪。审批通过后，可以在门岗使用。

---

## 哪些情况会导致无法提交

- 没有物品。至少需要一条物品明细。
- 某条物品缺少名称、数量或单位。

---

## 小贴士

- 每件物品单独一行并填写自己的数量。门岗会逐行核对。
- 照片是可选的，但清晰的照片有助于门岗确认物品。
