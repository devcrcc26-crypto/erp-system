# 审批收件箱

在**审批**中，您可以发起申请、跟踪自己提交的申请，并处理等待您审批的申请。

**找到与您相关的部分**

| 您的身份 | 请阅读 |
| --- | --- |
| 员工 | 发起申请、跟踪申请、草稿、条件回复，以及申请被退回时怎么办 |
| 所有审批人（团队负责人、部门负责人、专业负责人、人事、总经理、常务董事） | 查找等待您处理的申请，以及批准、退回、拒绝或有条件批准 |
| 人事经理、系统管理员 | 转派等待中的审批环节 |
| 总经理、常务董事、人事经理 | 代其他审批人批准或退回，以及报表 |

---

## 如何发起新申请

*（所有人）*

1. 在左侧菜单中，进入**新建申请**，打开**您想提交什么申请？**页面。
2. 查找申请类型：
   - 在**搜索申请类型**中输入，或
   - 点击分组，例如**考勤与工时**、**差旅**或**费用与补贴**，或
   - 从**最近使用**中选择。
3. 点击申请类型，打开对应表单。
4. 填写并提交表单。每种申请类型在本手册中都有单独的主题，介绍具体步骤。


> **提交后：** 您的申请已发送审批。申请被批准或退回时，您会收到通知。

---

## 如何跟踪您的申请

*（所有人）*

1. 在左侧菜单中，进入**审批**。
2. 点击**我的申请**标签页。
3. 顶部统计显示**全部**、**待处理**、**已批准**和**已拒绝**。
4. 可按标题或申请编号搜索，或按**类别**筛选。点击**重置**清除筛选。
5. 列表显示**申请编号**、**标题**、**类别**、**提交时间**、**状态**和**当前层级**。
6. 点击某条申请即可打开。右侧显示**审批链**以及申请当前在等待什么，例如*"等待 …"*或*"已全部批准 - 无需进一步操作"*。


**状态说明**

| 状态 | 含义 |
| --- | --- |
| 已提交 | 已发出，等待第一位审批人。 |
| 审批中 | 审批人正在审阅。 |
| 已退回 | 已退回给您修改。 |
| 已批准 | 已全部批准。 |
| 已拒绝 | 未获批准，申请已关闭。 |
| 已取消 | 已取消。仍保留在您的**我的申请**记录中（只读），但不再出现在审批人的列表中。 |

---

## 如何继续编辑草稿

*（所有人）*

1. 在左侧菜单中，进入**审批**，点击**我的草稿**标签页。
2. 列表显示**申请编号**、**标题**、**类别**、**最后修改**和**状态**。可使用**全部模块**按申请类型筛选。
3. 点击草稿继续填写，然后提交。

---

## 申请被退回时怎么办

*（所有提交申请的人）*

申请被退回时，您会收到退回通知。打开申请即可查看原因。

1. 在左侧菜单中，进入**审批** → **我的申请**，打开状态为**已退回**的申请。横幅会显示**此申请已退回**以及审批人的备注。
2. 阅读备注。
3. 如需修改申请，点击申请顶部的**编辑**（或在**我的申请**列表中该申请旁的**编辑**）。表单会带出您之前填写的内容，审批人的备注显示在顶部。修改后点击**保存**。页面会提示*"修改已保存。"*，并回到申请页面，状态仍为**已退回**。保存不会将申请送审。
   - 请假：在同一页面的申请详情中点击**编辑**。
   - 加班：**编辑**会打开加班表。请在加班表中修改条目，然后在加班表页面重新提交。加班申请在**审批**中没有**重新提交**按钮。
4. 准备好后，点击申请顶部的**重新提交**。如无需修改，可跳过第 3 步。
5. 在**重新提交申请**中，填写**给审批人的备注（可选）**说明您做了哪些修改。如有需要，点击**添加附件**，然后点击**重新提交**。点击**取消**可关闭而不重新提交。

申请会按当前内容从审批链的第一步重新开始。

> **重新提交后：** 页面会提示*"申请已重新提交"*。您的备注会与之前的备注一起显示在**重新提交 / 回复记录**中，供审批人查看。

> **草稿：** 已保存但未提交的申请是草稿。进入**审批** → **我的草稿**，点击旁边的**编辑**。保存草稿后仍为草稿（*"修改已保存。"*）。

> 您只能编辑自己的申请，且仅限草稿或已退回状态。申请处于待审批、已批准或已完成时，不会显示**编辑**。

---

## 如何回复条件

*（所有提交申请的人）*

审批人可以有条件地批准您的申请，此时您会收到通知。

1. 在**审批** → **我的申请**中打开该申请。
2. 阅读条件内容（Condition）。
3. 在 **Your response** 下填写回复。如有需要，点击 **Attach files** 添加文件。
4. 点击 **Submit response**。在审批人将条件标记为已解决之前，申请会显示 *"Response submitted - awaiting review"*。

## 如何查找等待您处理的申请

*（所有审批人）*

申请转到您的环节时，您会收到需要审批的通知。左侧菜单中的**审批**会显示等待处理的数量。

1. 在左侧菜单中，进入**审批**。
2. 点击**待我处理**标签页。
3. **待办事项**列会显示需要做什么。可按标题或申请编号搜索，或按**类别**筛选。
4. 点击某条申请即可打开。

## 决定前如何核对申请

*（所有审批人）*

1. 阅读申请详情和附件。标题下方会显示*"… 于 … 提交"*。
2. 如果申请是重新提交的，会显示*"已重新提交 N 次"*，请阅读**重新提交 / 回复记录**。
3. 查看右侧的**审批链**。标记为**当前**的环节就是正在等待的环节。

> **注意：** 只有申请到达您的环节时，您才能做出决定。决定按钮位于**决策**下方。

---

## 如何批准申请

*（所有审批人）*

1. 点击**批准**。
2. **备注（可选）**：填写备注。
3. 点击**批准**。

> **批准后：** 页面会提示*"层级已批准"*。如果还有下一位审批人，申请会转给他们；如果您是最后一位审批人，申请变为**已批准**，员工会收到通知。

---
<!-- /role -->

## 如何退回申请

*（所有审批人）*

当员工可以修改申请时，请使用退回。

1. 点击**退回**。
2. **给提交人的备注**：写明需要修改的内容。
3. 点击**退回**。

> **退回后：** 页面会提示*"申请已退回提交人"*。员工会收到通知，修改后重新提交。申请会从第一位审批人重新开始。

---
<!-- /role -->


<!-- role: HR, SUPERVISOR -->
## 如何拒绝申请

*（所有审批人）*

只有在申请完全不应继续时才使用拒绝。

1. 点击**拒绝**。
2. **拒绝原因**：填写原因，员工会看到。
3. 点击**拒绝**。此操作无法撤销。

> **拒绝后：** 页面会提示*"申请已拒绝"*。申请将关闭，员工会收到通知。

---
<!-- /role -->

## 如何有条件批准

*（所有审批人）*

当您原则上同意、但需要先确认某件事时，请使用有条件批准。

1. 点击**有条件批准**。
2. **条件**（必填）：写明需要解决的问题。
3. 点击**提交**。
4. 申请会停留在您的环节。员工回复后，您会看到*"员工已回复 - 可解决条件"*。
5. 条件满足后，点击**解决**，然后照常批准、退回或拒绝申请。

> **注意：** 条件未解决时，页面会显示*"请先解决全部条件后再操作。"*，您无法批准、退回或拒绝。

## 如何转派等待中的环节

*（人事经理、系统管理员）*

当审批人不在或已离职时使用。

1. 打开该申请。
2. 在**审批链**中，点击等待中环节上的**转派**。
3. **新审批人**（必填）：选择一名在职且可以审批的员工。
4. **原因**（必填，至少 3 个字符）：说明原因。
5. 点击**转派**。新审批人会收到通知。

## 如何代其他审批人批准或退回

*（总经理、常务董事、人事经理、系统管理员）*

如果申请停留在其他人的环节，您会看到**代 … 审批**和**代 … 退回**。

1. 点击**代 … 审批**或**代 … 退回**。
2. 阅读弹窗，其中会写明您所代理的环节和审批人。
3. 点击**代为审批**或**代为退回**。

原审批人会收到通知，该环节会记录由您代为处理。您不能对自己的申请，或您代他人提交的申请进行代理操作。

## 如何查看所有申请和公司报表

*（总经理、常务董事、人事）*

- **所有申请：** 在**审批**中点击**全部申请**标签页，查看公司所有申请。可使用搜索和**类别**筛选。
- **仪表板：** 在左侧菜单中点击**仪表板**。**概览**、**薪资与加班**和**运营**视图汇总了公司情况。
- **人力资源报表：** 在左侧菜单中，进入**人员** → **人力资源报表**。标签页包括**总览**、**请假与加班**、**薪资与支出**和**合同与考勤**。
