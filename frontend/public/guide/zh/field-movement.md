# 外勤与早退说明

如果月度考勤中某天有异常，请通过**外勤 / 早退说明**进行说明。异常类型包括**缺上班打卡**、**缺下班打卡**、**早退**和**无打卡**。同一类问题的多天可以一次说明。

> **注意：** 本表单中部分步骤名称和按钮目前只显示英文，本指南会在中文说明后附上屏幕上的英文文字。

**找到与您相关的部分**

| 您的身份 | 请阅读 |
| --- | --- |
| 员工 | 说明异常考勤，以及说明被退回时怎么办 |
| 说明审批人 | 如何审批说明 |
| 人事（人事经理、人事助理、人事专员） | 查看所有说明，以及代他人录入纸质表格 |

## 如何说明异常考勤

*（员工）*

人事处理完当月考勤后，您才能进行说明。人事批准某月考勤时，如果您有需要说明的日期，会收到通知。

1. 在左侧菜单中，进入**新建申请**。
2. 点击**外勤 / 早退说明**。表单分三步：选择月份（**Choose month**）、说明日期（**Explain days**）和确认并提交（**Review & submit**）。


> **注意：** 您也可以从**我的资料** → **考勤**开始。某月有异常日期时，页面横幅上会有 **Submit Explanation** 按钮。

## 第 1 步 — 选择月份

*（员工）*

1. 选择月份（**Month**）和年份（**Year**）。
2. 点击 **Check for flagged days**（检查异常日期）。
3. 查看结果：
   - 显示有 N 天需要说明：点击**下一步**。
   - 显示未找到异常日期：考勤完整，无需说明。
   - 显示该月考勤尚未处理：请等待人事上传并批准当月考勤。
   - 显示所有异常日期已有进行中的说明：您已为这些日期提交过说明，点击 **View in My Requests** 跟踪。

## 第 2 步 — 说明日期

*（员工）*

表格列出每个异常日期的**日期**、**打卡（上 / 下）**、**问题**和**说明状态**。

1. 勾选问题相同的日期。点击**全选兼容日期**可一次全选。问题类型不同的日期不能一起说明。
2. 点击**说明所选**，或在某一天上点击**说明**。
3. 在**当天发生了什么？**中选择：
   - **外勤 / 现场**：外出办公。填写**外出时间**（必填）、**返回时间**（可选）和**地点 / 目的地**（必填）。
   - **早退**：填写**外出时间**（必填）。
   - **忘记打卡**：在**忘记的是哪次打卡？**中选择**仅上班打卡**、**仅下班打卡**或**上下班均忘记**。**补录上班时间**和**补录下班时间**默认为您的计划时间，如有需要可修改。
4. **原因说明**（必填）：说明发生了什么。
5. **附件**（可选）：例如现场访问单。
6. 如需为不同日期设置不同时间，展开**按日调整时间**。
7. 如果说明的是已结束的月份，可能还需要填写**补录原因**。
8. 点击**保存草稿**，这些日期会显示为已说明。
9. 对其他日期重复以上步骤，然后点击**下一步**。不必一次说明所有日期。


> **注意：** “忘记打卡”在审批通过后会补录缺失的打卡。仅在有已批准的外勤或早退说明时，才会免除早退判定。

## 第 3 步 — 确认并提交

*（员工）*

1. 在 **Review your explanation** 中核对包含的日期（**Days included**）和将创建的记录（**Entries to create**）。
2. 如有需要，在 *"Anything else your supervisor should know?"* 中补充备注。
3. 点击 **Submit for Approval**（提交审批）。

> **提交后：** 页面会提示*"已提交审批。"*您的申请已发送审批。申请被批准或退回时，您会收到通知。

### 无法继续的原因

- *"请至少选择一天。"*
- *"保存前请选择原因。"*
- *"保存前请选择上班、下班或两者。"*
- *"请先保存至少一天的草稿再提交。"*
- 提示有未提交的草稿锁定了该月（**An unsubmitted draft is locking …**）：您之前保存了草稿但没有提交。从提示中打开并取消该草稿以解锁日期，然后重新开始。

## 说明被退回时怎么办

*（员工）*

说明被退回时，您会收到退回通知。打开说明即可查看原因。

1. 在左侧菜单中，进入**审批** → **我的申请**，打开状态为**已退回**的说明。横幅会显示**此申请已退回**以及审批人的备注。
2. 阅读备注。
3. 点击申请顶部的**重新提交**，在**重新提交申请**中填写**给审批人的备注（可选）**补充缺少的信息，如需提供证明，点击**添加附件**。
4. 点击**重新提交**。说明会从审批链的第一步重新开始。

> **注意：** 说明等待审批期间，您不能再次选择这些日期。说明被拒绝或取消后，可以重新说明这些日期。

## 如何审批说明

*（说明审批人）*

说明转到您这里时，您会收到需要审批的通知。

1. 在左侧菜单中，进入**审批** → **待我处理**，打开该说明。
2. 核对每一天的问题、所选原因、时间、地点和附件。
3. 选择**批准**、**退回**（填写**给提交人的备注**）或**拒绝**（填写**拒绝原因**）。员工会收到通知。

> **批准后：** 说明会应用到员工这些日期的考勤中。

## 如何查看所有说明

*（人事）*

1. 在左侧菜单中，进入**考勤与假期** → **外勤 / 早退说明**。
2. 选择**月份**、**年份**、**状态**和**员工**。
3. 顶部统计显示**全部提交**、**待审批**、**已批准**（已应用到考勤）和**已驳回或取消**。
4. 列表显示**单号**、**员工**、**期间**、**天数**、**状态**、**当前节点**和**提交时间**。
5. 点击某条说明可查看**说明的日期**和**员工备注**，或点击**在审批中打开**。

## 如何代他人录入纸质表格

*（人事）*

1. 在**外勤 / 早退说明**中点击**代他人新增**。
2. 在选择月份步骤中，按姓名或员工编号搜索员工（**Employee**），然后选择月份和年份。可以选择过去的月份。
3. 点击 **Check for flagged days**，然后按上文完成说明日期和确认并提交。

> **提交后：** 说明会显示*"由 [您的姓名] 代为提交"*，并按该员工的审批链审批。

## 人事须知

*（人事）*

- **员工何时可以说明。** 只有当月考勤导入并批准后，员工才能说明该月。批准某月考勤会通知所有有异常日期的员工。
- **锁定的日期。** 已保存但未提交的草稿，或正在等待审批的说明，会锁定相应日期，直到被取消或拒绝。
