# 外勤与早退说明

当您的月度考勤中有需要说明的日期时，您需要提交外勤说明来解释。例如缺少上班或下班打卡，或因在现场或外出办事而提前离开。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 为每个标记的日期提交说明。在**审批**中跟踪。 |
| 审批人 | 在说明转到您这里时进行审批或退回。 |
| 人事（人事经理、人事助理、人事专员） | 点击左侧菜单中的**考勤与假期**，然后点击**外勤 / 早退说明**，查看全部说明，并在审核考勤时核对。 |

**入口位置**
- 提交：点击左侧菜单中的**我的资料**，然后点击**考勤**。当某月有标记日期时，该页面会出现横幅，其中有**提交说明**按钮。您也可以点击左侧菜单中的**新建申请**，然后点击**外勤 / 早退说明**发起申请。
- 人事列表：点击左侧菜单中的**考勤与假期**，然后点击**外勤 / 早退说明**（仅人事可见）。

---

## 如何提交说明

1. 点击左侧菜单中的**我的资料**，然后点击**考勤**。如果该月有标记日期，横幅会显示需要说明的天数。
2. 点击**提交说明**。
3. 为每个标记日期填写说明；如表单要求，填写**迟到登记原因**。
4. 提交。说明进入审批流程，您可以在**审批**中跟踪。

> **接下来会发生什么：** 人事在考勤审核时检查说明。该月审批通过后，已有说明的标记日期将视为已解决。

---

## 小贴士

- 月末后尽快提交说明，并在人事审批该月考勤之前完成。
- 清楚描述原因，例如您当时所在的现场或办理的外出事务。
