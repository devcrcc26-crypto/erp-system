# 差旅补贴

差旅补贴是您出差或在现场工作期间的每日补贴。出发前您申请**预支**；行程结束后，您提交**结算**，把已领取的预支与实际出差天数进行核对。

**找到与您相关的部分**

| 您的身份 | 请阅读 |
| --- | --- |
| 员工 | 申请预支、提交结算、跟踪申请、取消，以及申请被退回时怎么办 |
| 差旅补贴审批人 | 如何审批差旅补贴申请 |
| 人事（人事经理、人事助理、人事专员） | 补贴标准、拨款、结算和登记差额 |

---

## 开始之前

*（员工）*

您的员工档案中必须设置差旅补贴标准。如果表单显示**未分配出差补贴标准**，请联系人事。设置之前无法提交。

---

## 如何申请差旅补贴预支

*（员工）*

1. 在左侧菜单中，进入**新建申请**。
2. 点击**差旅补贴申请**。表单分三步：**目的地类别**、**申请详情**和**确认并提交**。


## 第 1 步 — 目的地类别

*（员工）*

1. **行程类型**（必填）：选择**出差**或**现场派驻**。
2. **目的国家**（必填），然后选择**目的城市**（必填）。
3. **目的地类别**（必填）：会根据国家自动设置（*"根据国家自动设置。您可以更改此选项。"*），如有需要可修改。
4. 点击**下一步**。

## 第 2 步 — 申请详情

*（员工）*

1. 如果属于已批准的行程，请关联：
   - **现场派驻**行程：选择**现场派驻（可选）**，会自动填入城市和日期。
   - **出差**行程：选择**关联出行（可选）**，选择已批准的机票或出差，会自动填入目的地、日期和类别。如没有，保持*"- 不关联行程（独立差旅补贴）-"*。
2. **开始日期**和**结束日期**（必填）。
3. **出发时间**和**返回时间**（必填）。
4. **天数**（必填）：不能超过两个日期之间的自然日天数。
5. 核对**总天数**、**日标准**和**总金额**。
6. 如需申请更高的标准，打开**申请不同费率？**，填写**申请日补贴标准**（必须高于您已设置的标准）以及**申请更高费率的原因**（必填）。
7. **备注**（选填）：需要审批人了解的信息。
8. 点击**下一步**。


## 第 3 步 — 确认并提交

*（员工）*

1. 核对目的地、日期、天数和合计。
2. 如需修改，点击**上一步**。
3. 点击**提交申请**。

> **提交后：** 页面会提示*"差旅补贴申请已提交"*。您的申请已发送审批。申请被批准或退回时，您会收到通知。

---

## 行程结束后如何结算预支

*（员工 — 需要至少一笔已批准且已支付的预支）*

1. 在左侧菜单中，进入**新建申请**。
2. 点击**差旅补贴结算**，打开**新建差旅补贴结算**表单。表单分四步：**行程**、**车辆**、**已领预支**和**确认并提交**。

## 第 1 步 — 行程

1. **具体目的地**（必填）：城市和国家。
2. **出发日期**、**出发时间**、**返回日期**和**返回时间**（必填）：实际出发和返回的时间。
3. **天数**（必填）：实际出差的补贴天数。
4. 点击**下一步**。

## 第 2 步 — 车辆

1. 选填。如果使用了车辆，打开**使用车辆**，填写**出发里程**和**返回里程**。**返回里程**必须大于或等于**出发里程**。
2. 点击**下一步**。

## 第 3 步 — 已领预支

1. 勾选要结算的已支付预支。它们的目的地类别必须相同。标记为**待支付**的预支暂时不能结算。
2. 点击**下一步**。

## 确认并提交

1. 核对**计算**：**已领预支**减去您应得的补贴，以及差额。差额会显示为**余额归员工**或**余额归公司**。
2. 如需修改，点击**上一步**；确认无误后点击**提交申请**。


> **提交后：** 页面会提示*"差旅补贴结算已提交"*。您的结算已发送审批。结算被批准或退回时，您会收到通知。如果差额归公司，请按要求退回现金。

---

## 如何跟踪您的差旅补贴申请

*（员工）*

1. 在左侧菜单中，进入**审批**，点击**我的申请**标签页。
2. 点击您的差旅补贴申请，查看详情、已支付金额和**审批链**。

如果有员工向您汇报，左侧菜单中还会有**薪酬与差旅** → **差旅补贴**。**预支**标签页列出您本人和团队的申请，显示申请编号、**目的地**、开始日期、天数、**合计**、**已支付**（**已拨款**、**未支付**或**已结算**）和状态。**结算**标签页列出结算。

**状态说明**

| 状态 | 含义 |
| --- | --- |
| 草稿 | 已保存，尚未发出。 |
| 已提交 | 已发送审批。 |
| 审批中 | 正在审批。 |
| 已退回 | 已退回给您修改。 |
| 已批准 | 已批准，等待支付。 |
| 生效中 | 已支付，行程进行中或已结束。 |
| 已拒绝 | 未获批准。 |
| 已取消 | 已取消。 |

---

## 如何取消差旅补贴申请

*（员工 — 预支为**草稿**或**已提交**时）*

1. 打开该申请。
2. 点击**取消**。
3. 在**取消差旅补贴申请？**中确认。此操作无法撤销。

结算在**草稿**、**已提交**或**已退回**时可以取消，其关联的预支会被释放，可以重新结算。

---

## 申请被退回时怎么办

*（员工）*

申请被退回时，您会收到退回通知。打开申请即可查看原因。

1. 在左侧菜单中，进入**审批** → **我的申请**，打开状态为**已退回**的申请。横幅会显示**此申请已退回**以及审批人的备注。
2. 阅读备注。
3. 如需修改申请，点击申请顶部的**编辑**（或在**我的申请**列表中该申请旁的**编辑**）。表单会带出您之前填写的内容，审批人的备注显示在顶部。修改后点击**保存**。页面会提示*"修改已保存。"*，并回到申请页面，状态仍为**已退回**。日费率和总额会按您当前的出差补贴标准重新计算。
4. 准备好后，点击申请顶部的**重新提交**（如无需修改，可跳过编辑）。在**重新提交申请**中，填写**给审批人的备注（可选）**，如有需要点击**添加附件**，然后点击**重新提交**。

重新提交后，申请会从审批链的第一步重新开始。

> **重新提交后：** 页面会提示*"申请已重新提交"*。

## 如何审批差旅补贴申请

*（差旅补贴审批人）*

差旅补贴申请转到您这里时，您会收到需要审批的通知。

1. 在左侧菜单中，进入**审批** → **待我处理**，打开该申请。
2. 核对目的地、日期、天数和合计。
3. 点击**批准**。弹窗会显示 **Rate Summary**：**Configured Rate**（已设置的标准），以及员工申请更高标准时的 **Requested Rate** 和 **Override Reason**。
4. **Approved Daily Rate**（必填）：默认填入申请的标准或已设置的标准。如果您批准不同的标准，请修改。
5. 填写**备注（可选）**，然后点击**批准**。

如需退回或拒绝，请参阅**审批**主题。

## 如何设置员工的差旅补贴标准

*（人事）*

1. 在左侧菜单中，进入**薪酬与差旅** → **员工差旅补贴标准**。
2. 顶部统计显示**员工总数**、**已配置**和**未配置**。可按姓名、邮箱或部门搜索。
3. 为新员工点击**添加标准**，或在已有行上点击**更新**。
4. 为每个目的地类别填写**日标准**，并设为**启用**或**停用**。停用的类别不会出现在员工的申请表中。
5. 点击**保存**。

> **注意：** *"此费率按埃塞俄比亚比尔计偏低，请核对。"*提醒您该标准可能填错了币种。

## 如何查看所有差旅补贴申请

*（人事）*

1. 在左侧菜单中，进入**薪酬与差旅** → **差旅补贴**，打开**差旅补贴申请**。
2. 顶部统计显示**全部**、**草稿**、**待处理**、**已批准**和**已拒绝**。
3. 可按申请编号或目的地搜索，或按员工筛选。使用**预支**和**结算**标签页切换。
4. 点击某条申请即可打开。

## 如何记录拨款

*（人事 — 申请为**已批准**或**生效中**时）*

1. 打开该申请。
2. 点击**添加拨款**，打开**记录拨款**窗口。
3. 填写**付款凭证号**、**付款凭证日期**，以及**覆盖天数起**和**覆盖天数至**。窗口会显示这些天数对应的金额。
4. **收据（可选）**：上传文件。
5. 点击**保存**。

> **保存后：** 页面会提示*"拨款已记录"*。申请变为**生效中**，并显示**已拨款**。

## 如何结算申请并登记差额

*（人事 — 申请为**生效中**时）*

1. 打开申请，点击**结算**，打开**结算差旅津贴申请**窗口。
2. 填写**实际返回日期**。如需使用不同的天数，填写**覆盖实际天数**；留空则按日期自动计算。
3. 点击**保存**。**结算**部分会显示**应得总额**、**总拨款额**和**差额**（应付员工或应退公司）。
4. 差额结清后，点击**登记付给员工**（或**登记退回现金**），填写**付款参考号**或**收据编号**以及日期，然后点击**保存**。

对于员工提交的**差旅补贴结算**，请在**结算**标签页中打开。如果差额归公司，点击**登记退回现金**，填写**收据号**和**退回日期**，然后点击**保存**。
