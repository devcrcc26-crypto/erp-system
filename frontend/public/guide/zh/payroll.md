# 薪资管理（人事）

薪资每月运行一次。人事创建薪资运行，系统根据每位员工的合同、考勤、加班和请假计算薪资，人事复核后提交。随后由人事经理和总经理依次批准。工资发放后，人事生成工资单并发布给员工。

**各角色的职责**

| 角色 | 可执行的操作 |
| --- | --- |
| 员工（所有人） | 在**我的资料** → **工资单**中查看自己的工资单。 |
| 具有薪资权限的人事 | 创建、检查、重新计算并提交薪资运行，添加补发和自由职业者，标记已发放，生成并发布工资单。 |
| 人事经理、系统管理员 | 进行人事审批。 |
| 总经理、系统管理员 | 进行最终（总经理）审批。 |

**入口位置**
- 您的工资单：**我的资料** → **工资单**。
- 薪资运行（仅限薪资权限）：**薪酬与差旅** → **薪资与报销** → **薪资**。公司薪资设置也从该页面打开。

> **重要：** 薪资数据属于机密。只有具备薪资权限的人员才能打开本模块。

---

## 如何创建薪资运行

*(具有薪资创建权限的人事)*

1. 进入 **薪资**，点击 **新建运行**。
2. 在 **新建薪资运行** 中选择 **薪资月份**（年和月）。
3. 可选填写备注。
4. 点击 **创建并生成**。

> **接下来会发生什么：** 系统创建 **草稿** 状态的运行，并为该月薪资名册上的每位员工生成一条明细。每个月只能有一个运行；如果该月之前的运行已取消，系统会重新使用它。


---

## 如何复核运行

*(具有薪资权限的人事)*

1. 从 **薪资** 列表中打开运行。
2. 查看摘要：员工人数、应发合计、实发合计、个税合计、养老金数据和补发金额。
3. 使用 **仅显示标记**、筛选条件（**部门**、**专业**、搜索）查找需要关注的明细。
4. 打开某条明细，查看其组成：**天数**、**计薪天数**（按每月 30 天计）、收入、加班（**加班明细**）、**个税**、实发，以及 **银行**。
5. 检查明细上的 **标记**。每个标记都有原因，可查看 **标记说明**。

### 您可能看到的标记

| 标记 | 含义 |
|---|---|
| 缺少考勤 | 该月没有考勤记录。 |
| 缺少合同 | 没有合同覆盖该月。 |
| 加班未批准 | 该月加班未获批准。 |
| 零薪资 | 薪资为零。 |
| 手工调整 | 某项数据被手动修改。 |
| 离职人员 - 最后一个月 | 该员工本月离职。 |
| 登录已停用但仍在职 | 登录已停用，但员工仍在职。 |
| 本月有非活动期 | 员工本月部分时间处于非活动状态。 |
| 合同已到期未续签 | 合同已到期且未续签。 |

### 雇佣状态复核

在运行继续前，人事必须复核带有雇佣标记的员工。**雇佣状态复核** 面板会列出这些员工。逐一检查后，勾选 **我已核对这些员工** 以继续。

## 如何为员工添加奖金或税后补发

*(具有薪资编辑权限的人事；运行须为 **草稿** 或 **已复核**)*

1. 打开运行，找到该员工，点击 **编辑奖金/税后补发**。
2. 填写 **补发金额（ETB）** 或 **税后补发（ETB）**。金额须为零或正数。
3. 填写对应的原因。金额不为零时必须填写原因。
4. 可选：添加 **备注**。
5. 保存。

> **接下来会发生什么：** 补发金额加入明细，合计随之更新。重新计算时，您的补发和备注会保留。

---

## 如何添加或移除自由职业者

*(人事)*

自由职业者不会自动加入。

1. 打开运行，点击 **添加自由职业者**。
2. 从列表中选择自由职业者。只有在薪资名册上、处于有效状态且尚未加入本次运行的自由职业者才会显示。
3. 点击 **加入薪资**。

如需移除，请在该自由职业者的明细上点击 **从薪资中移除**。普通员工不能通过此方式移除。

> **注意：** 如果运行已在审批中，添加或移除自由职业者会使其退回 **草稿**，需要重新复核和审批。

---

## 如何重新计算运行

*(人事)*

在修改了该月的合同、考勤、加班或请假之后，使用 **重新计算**。

1. 点击 **重新计算** 并确认。

> **接下来会发生什么：** 系统根据当前的合同、考勤、加班和请假重新计算所有明细。奖金补发、备注和已添加的自由职业者会保留。如果运行已提交或已批准，会退回 **草稿**，需要重新复核、提交并再次审批，已生成的工资单也会被删除。

运行生成后若考勤发生变化，运行会显示 *考勤在生成本次工资后已变更*（请按提示重新生成或复核）。审批后若该月人事政策有变，运行会显示 *需要复核政策变更* 的提示。这些情况不会自动重新计算。

---

## 如何批准薪资运行

审批按以下顺序逐步进行，每一步都是运行页面上的一个按钮。

1. **标记已复核**（人事）：将 **草稿** 锁定以便人事复核，然后再提交。确认提示为：*锁定草稿，准备提交审批。*
2. **提交审批**（人事）：将已复核的运行提交给人力经理。如有标记的明细，需勾选 **我已复核标记的记录** 才能提交。
3. **人力批准**（人力经理或系统管理员）：确认人力批准。运行变为 **人力批准**。
4. **总经理批准**（总经理或系统管理员）：确认总经理批准。运行变为 **总经理批准**。
5. **标记已发放**（人事）：确认本月薪资已发放。运行变为 **已发放**。

> **规则：**
> - 运行必须先为 **已复核**，才能提交。
> - 运行必须先为 **已提交**，才能人力批准；必须先 **人力批准**，才能总经理批准。
> - 提交后的任何修改都会使运行退回 **草稿**。
> - 只有在总经理批准或发放之前，运行才可以取消。

---

## 如何取消薪资运行

1. 打开尚未 **总经理批准** 或 **已发放** 的运行。
2. 点击 **取消运行** 并确认。

> **接下来会发生什么：** 运行被取消，该月可以通过新的运行重新处理。

---

## 如何生成和发布工资单

*(人事)*

只有在运行为 **总经理批准** 或 **已发放** 状态时，才能生成工资单。

1. 打开运行，进入 **工资单**。
2. 点击 **生成工资单**。
3. 核对列表。打开某位员工的工资单可查看 PDF。
4. 点击 **发布给员工**，并在 **向员工发布工资单？** 的提示中确认。
5. 如需一次性下载全部工资单，点击 **全部下载 (ZIP)**。

> **接下来会发生什么：** 每位收到工资单的员工都会收到通知。员工可以在 **我的资料** 的工资单中查看自己的工资单，且只能看到自己的。

---

## 如何导出薪资

*(人事)*

在运行页面打开 **导出** 菜单：

- **工资表 (Excel)**：导出该运行的工资表。
- **银行转账函 (Word)**：导出银行转账函。导出前如有需要核对的内容，会先显示提醒。请在核对后再继续。

---

## 各角色权限

| 操作 | 谁 |
|---|---|
| 创建运行、编辑补发、重新计算、标记已复核、提交、标记已发放、取消、工资单、导出 | 具有薪资权限的人事 |
| 人力批准 | 人力经理或系统管理员 |
| 总经理批准 | 总经理或系统管理员 |
| 查看自己的工资单 | 所有员工 |

---

## 小贴士

- 创建运行前，先锁定该月的考勤和加班，以免数据在计算后变化。
- 尽早复核标记的明细，尤其是 **缺少考勤** 和 **缺少合同**。
- 每一笔奖金或补发都要填写清楚的原因，系统会强制要求。
- 只有在运行批准后才生成工资单，核对无误后再发布。
